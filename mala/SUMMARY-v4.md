## 4. 손님 모드 흐름 (v4)

```
재료 담기 → (사이드/맵기/국물/토핑 선택) → 💳 주문하고 결제하기
→ 결제 모달: 👛 지갑에서 카드 1장 터치해 꺼냄 → 카드를 리더기로 드래그(150px 이상) 또는 ⌨ 키보드 결제
→ 결제 성공 시 잔액 1회 차감 → 1.2초 조리 → 먹기 화면
→ 재료/토핑/사이드 클릭 · 숟가락 클릭(국물 3모금) → 전부 0이 되면 완식 모달
```

### 지갑 (v4 신규)
- 카드 4장: `MARA PASS`(마라탕 전용) · `SOPUNG CHECK`(체크) · `HOT POINT`(포인트) · `DRAGON BLACK`(프리미엄)
- 카드를 꺼내면 지갑 자리는 빈칸(반투명) 처리, "↩ 지갑에 다시 넣기"로 교체 가능
- 카드를 꺼내지 않으면 드래그·키보드 결제 모두 차단
- 결제 취소 시 주문 수정 가능, 잔액 부족 시 모달이 열리지 않고 안내

### 그릇 (v4)
- 300×300 정원(`aspect-ratio:1/1`), 재료·토핑은 국물 안쪽 원 영역(`overflow:hidden`)에만 배치
- 재료+토핑 수에 따라 4단계 자동 축소: 기본(≤6) → `.many`(7~9) → `.packed`(10~12) → `.jammed`(13+)
- 토핑은 그릇 **맨 윗줄**(노란 테두리 + 점선 구분선)에 표시
- 숟가락·젓가락 기본 위치를 그릇 가장자리로 이동해 재료 라벨을 가리지 않음
- 실측: 최대 구성(재료 9 + 토핑 4)까지 국물 원 밖으로 나가는 타일 0개

### 국물 색
| 맵기 | 색 |
|---|---|
| 순한맛 | 옅은 주홍 (#e58b4a) |
| 보통맛 | 붉은 주황 (#d2552b) |
| 얼얼맛 | 진홍 (#a8241a) |
| 마라폭풍 | 검붉음 (#6f0f12) + 안쪽 붉은 테두리 |
| 토마토 육수 | 맵기와 무관하게 토마토색 (#e0432c) — 맵기 색을 덮어씀 |
맵기 버튼 앞에 같은 색 점(●) 표시. 선택 즉시 0.5초 페이드로 전환.

### 먹기 규칙
- 재료·토핑·사이드 각 3입, 국물 3모금
- 남은 양 = 재료×3 + 토핑×3 + 사이드×3 + 국물3(재료가 있을 때만)
- **어떤 것을 먹어도 다른 항목이 리필되지 않음** (v2-1에서 수정, v4 재검증)
- 재료를 전부 먹으면 그릇에 "재료는 다 먹었어요! 국물·사이드를 마저 드세요" 표시
- 얼굴 표정: 기대 → 입 벌림(eating) → 행복(happy) → 복귀. 토핑/사이드/국물도 동일 애니메이션
