## 2. v22 최신 작업 상세 (2026-11-22) — 숟가락 · 팔 동작 · 짧은 목 · 상점 글자

### 1) 🐛 먼저 발견한 문제: 먹을 때 팔이 움직이지 않았음
- v5부터 있던 팔 동작(`eating-spoon`, `eating-chopsticks` 클래스)은 붙이자마자 `updateCharacterExpression()`이 다시 지워서 **실제로는 한 번도 재생되지 않았습니다.** 그릇의 큰 숟가락만 살짝 들렸다 내려왔습니다.
- v22에서는 팔 동작용 클래스(`sip-anim`, `chop-anim`)를 표정 갱신과 분리해 `playArm()`으로 따로 관리합니다.

### 2) 🥄 숟가락 동작 (국물 한 숟갈, 약 1.7초)
- **그릇의 큰 숟가락**: 살짝 들림 → 국물 속으로 기울며 담금 → 앞으로 밀며 뜸 → 수평으로 들어 올림(작은 흔들림) → 위로 올라가며 사라짐 → 제자리로 돌아옴. 뜬 뒤에는 숟가락 안에 **국물이 담겨 보이고**(현재 국물 색), 들어 올릴 때 **방울이 두 번 떨어지며**, 담그는 자리에 **물결**이 퍼집니다.
- **캐릭터의 왼팔**: 아래로 뻗어 뜸 → 팔꿈치를 접어 숟가락을 입으로 → 손목을 돌려 기울여 마심 → 내려놓음. 손에 든 숟가락에도 국물이 담겼다가 마시면 사라집니다.
- **머리**: 숟가락 쪽으로 고개를 숙여 마시고 돌아옵니다.
- **순서**: 예전에는 누르자마자 "후루룩" 소리와 입 벌림이 나왔는데, 이제 숟가락이 입에 닿는 시점(약 1초 뒤)에 맞춰 나옵니다. "국물 한 숟갈 뜨는 중…" → "호- 호- 후루룩—" → 맛 반응 순서입니다.
- 한 번 마시는 데 걸리는 시간이 약 1.65초에서 약 2.65초로 늘었습니다(그동안 다음 한입은 잠김).

### 3) 💪 팔을 더 자연스럽게
- 팔을 **소매(위팔) + 아래팔 + 손** 세 부분으로 나눴습니다. 어깨와 팔꿈치가 따로 꺾이고, 숟가락과 젓가락은 손목에서 따로 돌아갑니다. HTML에 `.forearm` 요소가 추가됐습니다.
- 기본 자세: 양팔이 어깨에서 살짝 벌어지고 아래팔이 안쪽으로 접혀 손이 몸 앞에 옵니다. 손에는 엄지가 생겼고, 숨 쉬듯 팔이 아주 조금 흔들립니다.
- **젓가락 동작(오른팔, 약 1.25초)**: 아래로 뻗어 집음 → 팔꿈치를 접어 입으로 → 젓가락 끝이 입에 들어감 → 내려놓음. 머리도 젓가락 쪽으로 숙입니다. 재료·토핑을 먹을 때 재생됩니다.
- 쉬고 있을 때 젓가락은 숟가락과 대칭으로 아래쪽을 향해 들고 있습니다(전에는 위로 세워 들었음).
- 팔이 얼굴 앞으로 올 수 있게 팔의 겹침 순서를 머리보다 위로 올렸습니다.

### 4) 🧑 목 길이 축소
- 머리를 9px 내려 보이는 목 길이를 절반 정도(약 18px → 약 9px)로 줄였습니다. 귀도 함께 내렸습니다.

### 5) 🏷️ 상점 버튼
- `💎 상점` 버튼이 좁은 화면에서 "상"과 "점"이 위아래로 갈라지던 것을, 항상 옆으로 나란히 한 줄에 나오도록 고정했습니다.

### 구현 메모 (후속 작업용)
- JS: `playArm(cls, ms)` 추가. `eatBroth()`의 진행 순서를 다시 짰고, `eat()`·`eatTop()`에서 `playArm('chop-anim', 1300)`을 부릅니다.
- HTML: 양팔에 `.forearm` 래퍼, 큰 숟가락과 손 숟가락 SVG에 `.spoon-soup` 타원, 그릇에 `#soupRipple`.
- CSS(v22 구간): `armSipL`/`foreSipL`/`spoonWrist`/`headSip`(숟가락), `armChopR`/`foreChopR`/`chopWrist`/`headChop`(젓가락), `spoonScoop`/`bigSoup`/`spoonDrip`/`rippleOut`(큰 숟가락), `armIdleL`/`armIdleR`(대기).
- `.torso`의 `transform`과 `z-index`를 없앴습니다(팔이 머리 위에 그려지도록). 가운데 정렬은 `margin-left:-70px`로 합니다.
- 복숭아 주스를 마실 때의 팔 동작은 예전 클래스(`eating-spoon`)를 그대로 써서 여전히 재생되지 않습니다. 필요하면 `playArm('sip-anim', …)`으로 바꾸면 됩니다.

### 확인한 것 / 확인하지 못한 것
- 브라우저에서 정지 화면으로 확인: 기본 자세(짧아진 목, 새 팔), 숟가락이 입에 닿는 순간, 젓가락이 입에 들어가는 순간, 큰 숟가락이 국물에 담겨 국물이 든 순간.
- 테스트용 스크립트로 `eatBroth()`를 실제로 실행: 안내 문구 순서, 국물 횟수 감소, 끝난 뒤 숟가락이 제자리로 돌아오고 다음 한입이 풀리는 것을 확인했습니다.
- 확인하지 않음: 동작 전체가 이어지는 모습을 영상처럼 보는 것(정지 화면 몇 장만 봄), 다른 헤어스타일·모자와 팔이 겹칠 때의 모습, 좁은 화면에서 상점 버튼, 모바일 화면, 카드 긁기 결제를 끝까지 진행하는 흐름, 알바 모드, Safari.

- JS 변경은 아래 4곳뿐입니다.
  1. `art()` 반환부: 재료 그림을 `<g filter="url(#foodDepth)">`로 감싸고 바닥 그림자 타원을 추가.
  2. `updateCharacterExpression()`: `head.style.background = 색` → `char.style.setProperty('--skin', 색)` (피부색을 CSS 변수로 전달).
  3. `applyEquippedVisuals()` 옷: `style.background` → `style.backgroundColor` + `.character`에 `--shirt` 변수 전달.
  4. `applyEquippedVisuals()` 그릇: 인라인 배경 대신 `--bowl-bg`, `--bowl-border`, `--bowl-rim` 변수 전달.

### 1) 🧑 캐릭터
