4. 재료 그림 준비 이전에 화면을 그리면서 이벤트 연결이 중단될 수 있다는 원인 설명 및 실행 순서 수정.

**주의:** 위 내용은 이전 답변의 수정 안내입니다. 실제 원인과 해결 여부를 이번 문서 작성에서 독립적으로 확인하지 않았으며, 마지막 수정 후 사용자의 정상 작동 확인도 없습니다. 결제 기능은 최우선 재검증 대상입니다.

### 조리를 위해 선택한 재료 전용 창

- 선택·취소 결과를 별도 선택창에도 즉시 반영하도록 안내됐습니다.

**설계 확인 필요:** 주문표에 같은 재료를 2개 이상 요구하는 주문이 있다면 단순 선택·취소 토글과 충돌할 수 있습니다. 주문 생성 수량과 선택 방식의 일관성을 확인해야 합니다.

## 11. 60초 연속 주문 타임어택
### 최종 요청 흐름
시작 → 재료 선택 → 조리하기·제공 → 새로운 주문 → 즉시 재료 선택 → 조리하기·제공 → 반복 → 시간 종료.

### 핵심 조건
- ‘시작하기’는 한 세션의 맨 처음에 한 번만 누릅니다.
- 주문 하나를 완성하면 다음 주문을 자동으로 표시합니다.
- 다음 주문에서도 재료를 즉시 선택할 수 있어야 합니다.
- 매 주문마다 시작 버튼이나 ‘한 번 더 일하기’를 누르지 않습니다.
- 타이머는 60초이며 주문이 바뀌어도 초기화하지 않습니다.
- 성공한 주문마다 10,000원을 적립합니다.
- 완료 주문 수와 이번 세션 수입을 누적 표시합니다.
- 시간이 끝나면 결과를 보여주고 재도전 또는 손님 모드 복귀를 선택합니다.

### 반복 수정 배경
자동으로 다음 주문을 보여주는 것만으로는 충분하지 않았습니다. 사용자는 다음 주문이 나온 뒤에도 시작하기를 다시 눌러야 하는 문제를 지적하며, 재료 선택이 곧바로 가능한 연속 진행을 재차 요청했습니다.
