## 2. 현재 사양 (pets-v2 기준, 유지해야 할 것)

### 2.1 공통
- **레이아웃** 왼쪽 사육장(`#habitat`) + 오른쪽 패널(이름 카드 → 상태창 → 급식/손 패널 → 행동 메뉴 → 꾸미기)
- **상태 수치** 3초 틱 감소(완화값): 포만감 −0.55, 행복 −0.3, 청결 −0.2(똥 1개당 +0.18), 똥 생성 4.5%. 마리모: 빛 −0.45, 수질 −0.35, 영양 −0.3, 털(fuzz) +0.35
- **표정·말풍선** 행복/보통/배고픔/불편 4종(눈꺼풀·입·홍조·땀) + 상태별 요청 문구 + 돌봄 직후 반응
- **낮/밤 주기** `DAY_MS=240000`(낮 2분+밤 2분, 실제 시각 기준). 다람쥐·게코 모두 적용: 밤엔 어둠 레이어+별+🌙 배지, 글로우로 동물 가시성 유지. 테스트 훅 `window.__FORCE_NIGHT`, `__DAY_MS`, `__HIDE_MS`
- **자율 행동**(3초 틱): 낮 6%/밤 0.4% 확률로 스스로 집·은신처 진입, 밤 5% 확률로 다람쥐 쳇바퀴 / 게코 등반(다람쥐는 성격 배율 적용)
- **청소 연출** 🧹 빗자루가 좌→우 이동하며 쓸기(1.9s) + 💨, 마리모는 🧽 + 🫧
- **초기화 버튼**, 이름 변경(8자, 인라인 입력), 똥 클릭으로도 치우기

### 2.2 피그미다람쥐
- **외형** SVG, 날씬한 몸통, 둥근 얼굴, 작은 귀·코, 반짝이는 눈, **수염 없음**
- **모프 6종**(이름 카드 아래 원형 스와치): 베이지 크림(기본) / 오레오 / 판다 / 실버 / 스노우 / 초코 크림
- **성격 4종**(모프 스와치 아래 칩, 기본 💕애교쟁이) — §3 v26 참조
- **메뉴** 밥 / 간식 / 청소 / 똥 치우기 / 핸들링 / 산책
  - 밥(종지): 🌰🌻🥜 · 간식(접시): 🫐🍓🍎🦴
  - 산책 = 산책볼: 바깥 배경으로 전환, 투명 공 안에서 4.4초 굴러다님
- **집 꾸미기** 나무집(클릭→고민 후 들어가기) / **이갈이 스틱**(클릭→갉기) / 쳇바퀴(클릭→2~8초 달리기) / 나무 바닥재 / 건초 / 물통(클릭→마시기)

### 2.3 게코도마뱀
- **외형** 릴리 화이트 모프: 베이지·연갈색 바탕 + 등·옆구리 크림 무늬. **초록색 규칙 없음**(사육장 배경도 샌드 톤). 얼굴 타원(rx35·ry32), 큰 눈, 홍조
- **메뉴** 밥 / 청소 / 똥 치우기 / 핸들링 — **간식·산책 없음, 관련 요청 대사도 없음**. 행복 회복은 핸들링·등반·물 마시기
  - 밥: 🦗🐛🥣 · 손 위 간식: 🦗 손에서 먹이기
- **집 꾸미기** 은신처(클릭→확률 진입) / 코코피트 바닥 / 물통(벽 위쪽, 좌우 반전 후 마심) / **등반 유목**(클릭→올라가 "꼭대기!" 후 내려옴, 행복 +12)

### 2.4 마리모
- **외형** 초록 방사형 그라데이션 구체 + 털 가닥 18개(`.fuzz`, 북슬 정도에 따라 투명도). **크기 = 영양**(`13% + 영양×0.16%`)
- **상태** 빛 / 수질 / 영양 / **단정함**(=100−fuzz)
- **메뉴** 밥 주기(🧪 영양제 스포이드) / 광합성(☀️ 빛 +25) / 물갈이·수조 닦기 / **🪥 칫솔로 다듬기**
- **수조 꾸미기** 조개 / 동그란 자갈(바닥, **색 6종 선택**) / 긴 수초 좌·우 / 새끼 마리모(둥실 애니메이션)
- 급식 박스(종지)는 마리모에 표시되지 않음

### 2.5 급식 흐름(다람쥐·게코)
1. 밥/간식 메뉴 → 팝업 없이 상태창 아래 **준비 박스**
2. 사료 버튼은 **이모지만**(이름은 aria-label). **클릭=담기**, 8px 이상 이동 시에만 드래그 판정(오류 토스트 없음). 종지 안 항목 클릭 시 빼기, **최대 4개**
3. '밥 주기' → 종지(간식은 납작 접시)가 **동물 옆 바닥에 자동 배치** → **0.85초마다 1개 소모** → 빈 그릇 1.2초 후 정리 → **재급식 가능**
4. 취소·모드 전환·초기화 시 타이머·상태 완전 리셋

### 2.6 핸들링(손 위)
- 큰 손 SVG가 올라오고 동물이 손바닥 위로. 손 패널: 🫳 쓰다듬기 / 간식 주기 / ⬇️ 내려놓기. 손 위 동안 일반 메뉴 잠김
- **쓰다듬기 → 잠들기**(다람쥐·게코): 약 1.3초(성격 배율) 뒤 눈 감고 💤. 자는 중 다시 쓰다듬으면 **물림**(행복 −4) 또는 **더 깊이 잠듦**(+3) — 확률은 성격별. 간식 주면 냄새에 깸. 내려놓으면 "잘 잤어요"

### 2.7 집·은신처 휴식
- 클릭 시 0.4~2.8초 고민 → 수락 확률(다람쥐 낮 80%/밤 35%, 게코 60%, 다람쥐는 성격 배율) → 진입
- **휴식 시간 랜덤**: `HIDE_MS(3분) × (0.45~1.55) × (밤 0.4 / 낮 1.3) × 성격 배율`, 하한 20초. `insideUntil`/`insideDur` 저장 → 새로고침해도 유지. 카운트다운 말풍선, 모든 행동 차단, 만료 시 행복 +8
