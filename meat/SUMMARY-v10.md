## 2. 현재 게임 흐름 (v10 기준)

```
[시작 화면] 나 캐릭터 선택 + 같이 올 사람(최대 2명) 선택
   ↓
[오프닝] 밤거리 → 고기집 문 앞 → 문 열림 "몇 분이세요?" → 입장 → 자리 착석   (⏭ 건너뛰기 가능)
   ↓
[주문] 📋 메뉴판 → 이모님이 쟁반 들고 걸어와 배달 (소주는 신분증 검사)
   ↓
[굽기] 왼쪽 고기 접시 → 불판으로 드래그 → 탭해서 뒤집기 → 양면 익힘 게이지
       가장자리 = 보온 구역(아주 느리게) / 가운데 = 가장 뜨거움 / 타면 알바생 불러 불판 교체
   ↓
[자르기] ✂️ 가위 도구로 탭 → 반으로 → 한입 크기까지
   ↓
[먹기] 고기를 '나' 또는 '동행(사람/접시)'에게 드래그 → 만족도·포만감 반영, 동행 말풍선 반응
       사이드·음료·식사는 탭해서 먹기
   ↓
[계산] 💳 성인은 카드 / 💵 미성년자는 현금 → 영수증 → 요구르트 서비스 (인원수대로)
```

## 5. 핵심 시스템

### 굽기
- 각 조각은 **양면 익힘도**를 가짐 (`cook[0], cook[1]`), 탭하면 뒤집기
- 메뉴별 `rate`(익는 속도), `perfect[min,max]`(딱 좋음 구간), `burn`(탐) 설정
- 속도: v1 → v2에서 43% 느리게 조정 (`dt*7 → dt*4`)
- 불판 열 분포: 가운데 1.25배, 가장자리로 갈수록 감소. **가장자리 20%(점선 바깥)는 보온 구역 — 12% 속도**
- 판정: 완벽(양면 모두 perfect 구간) / 괜찮음 / 덜 익음(페널티) / 탐(페널티) / 아삭아삭(사이드 생으로, 버섯 제외)
- 탄 조각은 불판에 찌꺼기를 남기고 열효율을 떨어뜨림 → 알바생 불판 교체
- 연기·기름 튀김 파티클, 숯불 깜빡임, 지글지글 소리 크기가 고기 양에 비례

### 자르기
- 가위 도구로 탭 → 반으로 분할, 한입 크기(폭 ≤ 50px)까지 반복
- 날고기(익힘 < 18)는 "조금 익힌 뒤 잘라요"
- 차돌박이·닭곱창·사이드는 자를 필요 없음

### 먹기 / 주기
- 한입 크기 조각을 **나**(캐릭터 자체) 또는 **동행**(사람 또는 접시)에게 드래그
- 드래그 중 사람 주변에 점선 하이라이트
- 만족도: 완벽 +8, 괜찮음 +4, 아삭 +3, 쌈 조합 +6, 덜 익음 −6, 탐 −4 (사이드는 ×0.6)
- 포만감: 고기 +6, 사이드 +3, 식사류 +3~5, 음료 +1~2. 100% 되면 "배불러요"

### 환풍 후드 (드래그 가능)
- 불판 위 덕트를 위아래로 드래그 (150~300px). 주름관처럼 늘어남
- **내리면** 연기가 후드로 빨려 들어가 사라짐, **올리면** 연기가 천장에 머묾

### 결제
- 성인(19세↑): 💳 카드 (긁는 소리) / 미성년자: 💵 현금 (지폐 세는 소리), 미성년자는 카드 불가
- 계산 후 주문 불가, 계산서 → 영수증
- 요구르트 서비스: 나 1개(탭해서 마심) + 동행 수만큼(각자 접시 옆, 자동으로 "쪽~" 마시고 사라짐)

### 신분증 검사 (소주)
- 모달에서 **나 + 동행 중 누구 신분증을 보여줄지 선택** (카드에 사진·이름·생년월일·주소)
- 성인이면 통과(이후 재검사 없음), 동행 걸 쓰면 그 사람이 한마디
- 미성년자(하은 17 / 동생 15) 신분증 → 거절

## 6. 비주얼 (v8 대규모 리뉴얼)

- 고기: 네모 → **조각마다 랜덤한 유기적 실루엣**, 메뉴별 텍스처(비계 층·마블링·뼈·주름·기름층)
- 익힘 연출: 비계 흰색→황금색, 마이야르 갈색 얼룩, 석쇠 자국 그라데이션, 기름 윤기, 수축(6%), 탄 자국
- 모든 조각에 입체 그림자·외곽선·상단 하이라이트
- 사이드: 주름진 상추, 톱니 깻잎, 김치(흰 줄기+양념+고춧가루+깨), 마늘 쪽, 양파 링, 새송이, 파채
- 접시: 흰 접시 + 파란 테두리 라인, 림 그라데이션 (식당 접시)
- 가게: 나무 벽, 소주병 선반, 칠판 메뉴, 조명 글로우, 환풍 덕트
- 오프닝 거리: 별·달, 붉은 등, 깜빡이는 네온 간판, 창문 빛, 미닫이 유리문, 입간판
