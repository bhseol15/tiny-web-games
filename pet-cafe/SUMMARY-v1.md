## 1. 인터뷰 결과 (확정된 기획)

| 항목 | 결정 |
|---|---|
| 게임명 | pet-cafe |
| 형식 | PWA 모바일 웹 게임 (단일 HTML, 세로 화면) |
| 핵심 장르 | 간식을 주거나 만지는 **힐링 게임** |
| 아트 스타일 | 귀엽고 조금 현실적인 → 최종: **부드러운 일러스트**(외곽선 없음, 파스텔, 작고 자연스러운 눈 + 풍부한 표정, 실제 동물 비율에 살짝 가깝게, 엎드려 쉬는 기본 포즈) |
| 펫 종류 | 고양이, 강아지, 토끼, 햄스터, 미어캣, 수달, 앵무새 (종마다 색·모습 다른 여러 마리 예정) |

| 교감 방식 | 터치로 쓰다듬기, 간식 드래그해서 주기, 장난감 놀아주기, 사진 찍기, 부르기/말 걸기 |
| 성장 요소 | 카페에서 **5번 이상 플레이 → 임시보호** 가능, 집에서 돌보고 조건 충족 시 **입양** → 집에서 키움 |
| 비주얼 | AI 생성 이미지 |
| 모션 | 간식/만질 때 **자연스러운 움직임** (프레임 전환 + CSS 모션) |

## 2. 아트 제작 경과

스타일 탐색 순서: 현실적 일러스트 → 마스코트 캐릭터 → 3D 애니메이션풍 → (AI 티 지적) 2D 셀/수채화 → 귀여운 2D → **부드러운 일러스트(최종 승인)**.

파이프라인: `flux-3-image`(흰 배경 생성) → `riverflow` 투명 컷아웃/표정 변형 → `build.py`에서 리사이즈·WebP·base64 임베딩.

### 생성된 이미지 (image/ 폴더)
- 기본 일러스트 9종: 주황 고양이, 회색 고양이, 골든리트리버, 코기, 토끼, 햄스터, 미어캣, 수달, 앵무새
- 배경 2종: 카페 내부(bg-cafe), 집 거실(bg-home)
- 포즈 프레임(기본/행복/먹기) 완료: 주황 고양이, 회색 고양이, 골든리트리버, 코기, 토끼
- 부분 완료: 햄스터(기본만). 미어캣·수달·앵무새는 **임시 이미지**(흰배경 플러드필 컷아웃, 테두리 거칠음)
- 없는 프레임은 기본 프레임으로 대체 (v2 에서 교체 예정)

## 3. v1 구현 내용 (`pet-cafe-v1.html`, 약 614KB 단일 파일)

### 화면
- **로비**: 코인, 카페 입장 / 우리 집 / 친구 도감 / 앨범 / 상점
- **입장권**: 10·20·30·60분 (10분 = 100코인). 구매 즉시 카운트다운 시작
- **카페**: 배경 + 펫 9마리 배치, 상단 타이머(1분 이하 경고), 하단 교감 패널
- **우리 집**: 임시보호·입양한 펫만 표시, 시간 제한 없음
- **도감 / 앨범 / 상점**

### 교감 5종 + 모션
| 교감 | 조작 | 모션/피드백 |
|---|---|---|
| 쓰다듬기 | 펫 위를 손가락으로 쓸기 | 손가락 위치 따라 기울어짐·눌림(squash), 하트 파티클, 진동, 행복 프레임 |
| 간식 | 트레이에서 펫 위로 드래그&드롭 | 먹기 프레임 + 씹는 바운스, 부스러기, 선호 간식이면 보너스 |
| 놀아주기 | 장난감 드래그&드롭 | 펫이 통통 뛰어 이동(spring easing), 행복 프레임 |
| 사진 | 버튼 | 플래시 효과, 앨범 저장, +10코인 |
| 부르기 | 버튼 | 호감도·성격(낯가림)에 따라 다가오거나 무시(고개 돌림) |
- 공통: 숨쉬기 idle 애니메이션, 무작위 꼼지락/말풍선, 프레임 크로스페이드(0.22s)

### 성장·경제
- 호감도 0~100, 교감마다 상승 + 코인 획득, 50 돌파 시 안내
- 세션 중 교감한 펫마다 `plays` +1 (세션당 1회). **plays ≥ 5 → 임시보호 신청**
- 임시보호: 집에서 **3일 돌봄(하루 1회 카운트) + 호감도 ≥ 60 → 입양** (보너스 300코인). 돌려보내기 가능
- 퇴장 시 교감한 펫 수 × 20 코인 보너스, 매일 첫 접속 +200 코인, 시작 코인 1000
- 상점: 간식 6종(소모), 장난감 5종(영구)
- 펫별 성격/선호 간식/선호 장난감/낯가림 수치

### 저장·PWA
- `localStorage` 자동 저장 (`petcafe-save-v1`), 앱 재접속 시 남은 입장권 시간이면 카페로 복귀
- 인라인 manifest(홈 화면 추가, standalone), `sw.js` 동봉(같은 폴더에 두고 http(s)로 서비스하면 오프라인 캐시)
- 디버그 메뉴(우하단 ⚙): 코인 추가, 입장권 15초, 플레이 5회 채우기, 입양 조건 충족, 세이브 초기화

### 검증
- jsdom 자동 테스트: 부팅 → 입장권 구매 → 쓰다듬기/간식/놀기/사진/부르기 → 임시보호 → 퇴장 → 집 → 입양 → 도감/앨범/상점 → 타이머 만료, 전 구간 에러 0
- 참고: 채팅 파일 미리보기 URL 은 스크립트 실행이 차단(CSP sandbox)되므로, **파일을 다운로드해 로컬/호스팅에서 열어야** 동작합니다.
