# SUMMARY v1 — 몬스터 트레일 (pokemon 프로젝트)

- 결과물: `pokemon-v1.html` (단일 파일, 설치 없이 브라우저에서 실행)
- 작성일: 2026-11-22
- 게임 내 제목: **몬스터 트레일** (오리지널 몬스터를 쓰기로 해서 제목과 이름을 모두 새로 지음)

## 1. 인터뷰 결과 (1차)

| 질문 | 결정 |
|---|---|
| 핵심 장르 | 탐험 + 포획 + 배틀 RPG |
| 캐릭터 | 오리지널 몬스터 (포켓몬 이름·그림 미사용) |
| 그래픽 | 애니메이션 느낌 (굵은 외곽선, 큰 눈, 통통 튀는 움직임) |
| v1 범위 | 크게 (몬스터 30종 이상, 맵 여러 개, 체육관, 상점, 저장) |

인터뷰에서 묻지 않고 제가 정한 것: 조작 방식, 맵 구조, 타입 수, 난이도 곡선, 전설 몬스터, 게임 제목.

## 2. v1에 들어간 것

### 플랫폼·조작
- 웹: 방향키/WASD 이동, Z/Enter 확인, X/Esc 메뉴
- 모바일: 화면 아래 십자키 + A/B 버튼 (터치 기기에서 자동 표시), 대화창 탭으로 넘기기
- 화면 크기에 맞춰 자동 조절, 세로·가로 모두 동작

### 월드 (맵 9개, 남→북 일직선)
1. 새벽마을 (집, 연구소, 회복 센터, 상점)
2. 1번 도로
3. 풀잎마을 (체육관 1: 로즈, 풀)
4. 2번 도로
5. 메아리 동굴 (전설 「천둥신수」: 배지 2개 이후 등장)
6. 용암마을 (체육관 2: 카이, 불)
7. 눈보라 길
8. 눈꽃마을 (체육관 3: 유키, 얼음)
9. 챔피언 로드 (챔피언 레온, 클리어 후 전설 「심연왕」)

- 마을 북쪽 출구는 해당 체육관 배지가 있어야 통과
- 도로마다 트레이너 2명 (시야에 들어오면 배틀), 총 10명
- 건물은 문에 부딪히면 바로 기능 실행 (실내 맵 없음)

### 몬스터 34종
- 스타터 3계열 × 3단계: 새싹몽(풀), 불씨롱(불), 물방구(물)
- 일반 23종 + 전설 2종
- 타입 8개: 노말, 불, 물, 풀, 전기, 땅, 얼음, 어둠 (상성표 있음, 전기→땅은 무효)
- 레벨업 진화, 그림은 전부 코드로 그림 (이미지 파일 없음)

### 배틀
- 턴제, 스피드 순서, 자속 보정, 급소, 명중률
- 기술 36개, 타입별 습득표, 기술 4칸 (넘치면 잊을 기술 선택)
- 상태이상: 화상, 마비 / 능력 변화: 공격·방어 랭크
- 교체, 아이템 사용, 도망
- 경험치: 싸운 몬스터 100%, 나머지 파티 40%
- 포획: 캡슐 3종, HP가 낮거나 상태이상이면 잘 잡힘, 흔들림 연출
- 전멸 시 소지금 1/5을 잃고 마지막 회복 지점으로 이동

### 그 외
- 상점 (마을마다 품목 다름), 아이템 8종
- 파티 6마리 + 보관함
- 도감 (본 것/잡은 것 구분)
- 저장: 브라우저 localStorage, 맵 이동·배틀·회복 후 자동 저장
- 효과음 (간단한 전자음)
- 챔피언 클리어 후 박사가 나머지 스타터 2마리를 줌

## 3. 확인한 것과 못 한 것

확인함
- 실제 브라우저에서: 타이틀 → 새 게임 → 연구소에서 스타터 선택 → 1번 도로 이동 → 트레이너에게 발견 → 배틀 화면 진입과 기술 선택
- 자동 테스트로: 9개 맵의 출입구·문·NPC 도달 가능 여부, 34종 그리기와 기술 구성, 배틀 승리, 레벨업, 기술 습득, 진화, 포획, 패배 후 복귀, 체육관 배지, 챔피언전, 전설전, 상점 구매, 배지 관문, 저장/불러오기

못 함
- 실제 휴대폰에서의 터치 조작 (십자키·A/B 버튼은 코드만 작성, 기기 테스트 없음)
- 처음부터 끝까지 사람 손으로 한 번에 플레이 (난이도·레벨 곡선은 계산으로만 맞춤)
- 브라우저 확인 도중 테스트용 브라우저가 끊겨서, 배틀 중반 이후 화면은 눈으로 보지 못함

## 4. 알려진 한계

- PP(기술 횟수 제한) 없음
- 몬스터 뒷모습 없음 (내 몬스터는 좌우 반전)
- 음악 없음
- 건물 실내, 라이벌, 스토리 이벤트 없음
- 저장은 같은 기기·같은 브라우저에서만 유지
