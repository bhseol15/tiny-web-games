## 1. 버전별 누적 변경 이력

### v1 — 기본 게임 골격
- 6교시 스테이지: 국어 김수현 / 수학 박정훈 / 영어 Emily / 과학 이도윤 / 사회 최민지 / 음악 정하늘
- 선생님 상태 머신: `safe(판서)` → `warn(예고 말풍선)` → `turned(뒤돌아봄)`; 스테이지마다 예고 시간·돌아보는 시간·간격·노예고 확률·페이크 확률 다름
- 눈치: 돌아본 상태에서 클릭 → ❤️ -1 + 감점, 3회면 스테이지 실패 → 재도전
- 콤보: 0.9초 내 연타 유지, 5콤보마다 배율 +0.5 (최대 ×3)
- 상점(교시 사이): 한입 크기 / 짝꿍 도우미(자동) / 콤보 마스터 / 눈치 레이더 / 반성문(❤️+1)
- 점심시간 보너스 라운드(15초 프리 클릭), 남은 시간×3 보너스
- 간식 6종 **AI 실사 사진** 생성 → WebP·base64 내장 (새우깡·초코파이·곰젤리·삼각김밥·붕어빵·컵떡볶이)
- 키: `Space` 먹기 · `Enter` 진행 · `1~5` 상점
- 선생님은 CSS 도형

### v2 — 선생님 실사화
- 선생님 6명을 **AI 생성 캐릭터 시트**(뒷모습 판서 / 어깨 너머 흘끗 / 정면 응시 3포즈)로 교체
  - 한 장에 3포즈를 같이 생성해 외형 일관성 확보 → 자동 분할 + 배경 누끼(플러드필 기반) + 440px WebP 내장
  - 흰 가운(과학)이 누끼에서 날아가는 문제 → 청록 가운으로 재생성
- 상태별 포즈 전환 애니메이션(판서 흔들림 / 흘끗 / 휙 등장), 스테이지 소개 아바타도 실사
- 간식 흰 배경 블렌딩 수정, 이미지 프리로드, Enter 중복 실행 방지

### v3 — 대규모 시스템 확장
1. **짝꿍 경쟁**: 책상 2개(나/짝꿍), 짝꿍 AI 4명 중 랜덤. 안전할 때 먹고 예고에 반응속도(0.1~0.8s)로 숨김, 늦으면 똑같이 걸려 10초 정지. 교시 결과 VS 화면, 짝꿍보다 많이 먹으면 **+20% 보너스**
2. **매점(20초 제한)**: 쉬는 시간마다 카운트다운, 간식 최대 4개 가방에 담아 지참, 0초가 되면 자동 수업 시작. 키 `1~6` 간식 / `A S D F G` 업그레이드
3. **캐릭터 꾸미기**: 이름·머리모양 4·머리색 8·옷색 8·액세서리 5(안경/머리띠/헤드폰/모자). 뒷모습 SVG, localStorage 저장
4. **걸리면 뒤로 나가기**: CSS 컷신(내 캐릭터가 교실 뒤로 걸어감) + 선생님 대사 + **10초 카운트다운 정지**(타이머·짝꿍은 계속), 먹던 간식 압수
5. **냄새·소리 → 난이도**: 간식마다 `noise`(한 입마다 의심 ↑), `smell`(꺼내놓은 동안 지속 의심 ↑)
6. **선생님 특성**: `eye`(시력) · `nose`(후각) · `ear`(청력) · `scary`(무서움) 수치
   - 쉬움: 국어(👓시력 나쁨·🤧비염) / 어려움: 과학(👃후각 1.6), 음악(👂청력 2.0·😡무서움 2.5)
7. **의심 게이지**: 선생님 머리 위. 70%↑ 깜빡, 100% 차면 예고 없이 즉시 돌아봄("킁킁… 무슨 냄새야?!")
8. **과목·이름 명찰**: 머리 위 `과학 이도윤 👃👓`
9. **숨기기**: `H`/`Shift`/버튼. 먹으면 간식 노출, 숨기는 데 0.55s(빠른 손 업그레이드로 단축)
   - 돌아봤을 때 노출 → 시력 판정으로 걸림(10초) / 숨기는 도중 → "덜 숨겼다!" 3초 정지 + 의심↑ / 완전 숨김 → 안전
   - 노예고(갑작스런) 턴은 발각 확률 50%로 완화
- 기타: WebAudio 합성 효과음(바삭/삐/호통), 실패 시 가방 간식 반환, 업그레이드에 **빠른 손** 추가(짝꿍 도우미 제거), 점심 라운드는 매점으로 대체

### v4 — 비주얼 다듬기
- **교과서(숨기기용 책)** 약 2배 크기, 교시마다 과목 교과서로 변경(국어 빨강·수학 파랑·영어 보라·과학 초록·사회 주황·음악 남색), 짝꿍 책도 동기화
- **간식 일러스트**: 실사 → 파스텔 톤 귀여운 스티커 스타일 6종 재생성, 투명 배경
- **먹을수록 줄어듦**: 한 입마다 오른쪽부터 베어문 자국(`clip-path` 지그재그)으로 잘려 나가고 남은 입 수 라벨 갱신, 짝꿍 간식도 동일(다 먹으면 새 간식)

## 2. 현재(v4) 게임 흐름

```
시작 → 캐릭터 꾸미기 → 매점(20s, 초기 150p + 새우깡 1개)
  → 1교시 소개(선생님 특성·가방·목표) → 수업
      · 안전: 먹기(Space/탭) → 콤보/의심↑ → 적절히 숨기기(H)
      · 예고: 숨기기!  · 돌아봄: 노출이면 걸림 → 10초 뒤로 나가기
      · 목표 달성 → CLEAR / 시간 종료·❤️0 → 실패(재도전)
  → 결과(VS 짝꿍, 보너스) → 매점 → 2교시 … → 6교시 → 하교 완료(최고 기록)
```

### 핵심 수식
- 한 입 점수 = (간식 pts + 한입 크기 Lv) × 콤보 배율
- 의심 증가: 한 입마다 `1.5 + noise × ear × 6`, 노출 중 초당 `smell × nose × 4`
- 의심 감소: 숨김 10/s, 노출 4/s (눈치 레이더 Lv당 +15%)
- 걸림 감점 = 목표 × 5% × scary, 숨기기 시간 = 0.55 − 0.1 × 빠른 손 Lv (최소 0.15s)
- 짝꿍 점수/입 = (간식 pts + 1) × (1 + 0.22 × 스테이지)

### 업그레이드
| 이름 | 효과 | 기본가 | 배율 | 최대 |
|---|---|---|---|---|
| 🍽️ 한입 크기 | 한 입 +1p | 80 | 1.6 | 8 |
| 🫳 빠른 손 | 숨기기 −0.1s | 100 | 1.7 | 4 |
| 🔥 콤보 마스터 | 콤보 유지 +0.15s, 최대 배율 +0.5 | 120 | 1.7 | 5 |
| 📡 눈치 레이더 | 예고 +0.15s, 노예고 확률 −8%, 의심 감소 ↑ | 200 | 1.8 | 4 |
| 📝 반성문 스킬 | 교시마다 ❤️ +1 (최대 5) | 350 | 2.2 | 2 |

### 조작
- PC: `Space` 먹기 · `H`/`Shift` 숨기기 · `Enter` 진행 · 매점 `1~6` 간식, `A S D F G` 업그레이드
- 모바일: 간식 탭 = 먹기, 하단 버튼 = 숨기기, 더블탭 확대 방지

## 3. 에셋 & 빌드 파이프라인

```
image/                      생성 원본 (jpg/webp/png)
assets.json                 모든 에셋의 base64 data URL (간식 6 + 선생님 6×3 포즈)
class-template.html         게임 소스 (ASSETS = __ASSETS__ 플레이스홀더)
build_assets.py             (v1) 간식 사진 축소·인코딩
build_teachers.py           (v2) 선생님 시트 3분할·누끼·인코딩
inject.py <ver>             template + assets.json → class-v{ver}.html
sim.js / sim3.js            Node 헤드리스 시뮬레이션(DOM 스텁)으로 전 흐름 검증
```

- 선생님: `gemini-nano-banana-2.1` 16:9 캐릭터 시트 → 열 밀도 기반 3분할 → 경계 연결 흰 영역 플러드필 누끼 → 440px WebP
- 간식: v1 `grok-imagine-image-quality` 실사 → v4 `riverflow-v2.5-fast` 투명 배경 스티커 일러스트, 300px WebP
- 학생 캐릭터: 인라인 SVG(색·머리·액세서리 파라미터), 컷신도 동일 SVG 재사용

## 4. 검증 방식
- `node --check`로 문법 검사
- 헤드리스 시뮬레이션: 꾸미기 → 매점 타이머 자동 진행 → 6교시(사람 같은 페이싱: 의심 70%에서 숨김, 4입마다 숨김) → 걸림 컷신/부분 숨김/의심 게이지 발동/실패 재도전 흐름 확인
- 공유 URL로 정적 프리뷰(수업·컷신·매점·책 덮힘·베어문 상태) 스크린샷 확인
  - 공유 뷰어는 CSP로 스크립트가 막혀 실행 플레이는 불가 → 로컬에서 파일을 열어 플레이
