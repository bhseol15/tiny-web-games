## 3. 게임의 전체 방향

- 브라우저에서 실행하는 **단일 HTML 인형뽑기 게임**입니다.
- 실제 3D 엔진보다는 원근감, 깊이, 그림자, 가림 순서를 활용하는 **2.5D 표현**이 기준입니다.
- 사용자가 만족했던 포켓몬 인형 외형은 유지합니다. 별도 요청 없이 전면 재디자인하지 않습니다.
- 개선의 핵심은 조작 편의성, 사실적인 집게 동작, 인형과 집게의 정렬, 공간감입니다.
- PC의 키보드·마우스와 모바일의 터치를 모두 고려합니다.
- 새로운 기능을 추가할 때 기존 코인·지폐·트레이·보관함·난이도·리필 규칙을 보존합니다.

## 4. 어제까지의 누적 작업 이력

1. 원본 게임의 조작 방향, 모바일 판정, 종료 안내, 획득 표시 개선 요청.
2. 사용자 시점의 방향을 ↑ 안쪽 / ↓ 바깥쪽으로 정리.
3. 집게, 바닥 그림자, 착지점의 좌표 정합성과 크레인 움직임 반복 개선.
4. 단일 HTML 포켓몬 게임 제작 및 포켓몬 인형 6종 외형 정리.
5. 인형 확대, 코인 투입구, 금속성 3발 집게, 빨간 조이스틱 도입.
6. 인형 실제 운반, 운반 중 낙하, 성공 코인 보상, 출구 복귀 추가.
7. 2.5D 공간감, 출구 깊이, 수령 트레이, 터치 보관, 종류별 수량 표시 추가.
8. 조작부·돈 투입구 재배치, 지폐 1장 = 2판, 보유 지폐 표시 정리.
9. 한지우 등장 오프닝 및 인형을 품에 안고 퇴장하는 연출 개선.
10. 느린 하강·상승·운반, 작은/큰 인형 구분과 차등 보상 적용.
11. 인형 개수 18개 → 28개 → 40개로 확대, 실패 시 근처 인형 흔들림 추가.
12. 줄 풀림·감김, 작은/큰 인형 혼합 배치, 전체 소진 후 자동 리필 추가.
13. 앞줄 인형에 집게가 닿지 않던 접근 범위 문제 수정 안내.
14. 마지막으로 성공 난이도 상·중·하 선택 추가.

## 5. 오늘 작업 이력 — 요청과 상태 구분

### 5.1 오프닝 자막을 소리로 바꾸기 — 미완료 / 방식 미확정

**사용자 요청:** 오프닝에서 사람이 나올 때 자막 대신 소리가 나면 좋겠음.

논의된 선택지:
1. 기존 설명을 읽어주는 음성.
2. 캐릭터 대사 + 발걸음·돈 투입·집게 동작 등의 효과음.
3. 효과음만 사용.

이전 답변은 2번을 추천했으나 사용자가 방식을 확정한 기록은 없습니다. 자막 제거 범위, 목소리, 효과음 구성도 미확정입니다.

- ‘소리 켜고 시작’ 버튼은 브라우저 자동재생 제한 대응을 위한 **제안**이지 반영 완료 사항이 아닙니다.
- 실제 음성 파일 생성, 재생 로직 추가, 자막 제거 완료를 확인할 수 있는 기록이 없습니다.
- 다음에 음성 작업을 한다면 재생 시작·건너뛰기·Esc·새 게임 시 음성이 겹치거나 남지 않도록 처리해야 합니다.

### 5.2 6종을 모으면 특별 포켓몬 선물 — 이후 최종 버전에서 반영 안내

**사용자 요청:** 6종류의 포켓몬을 모으면 뮤 같은 좋은 포켓몬 인형을 선물.

초기에는 보상 규칙 및 오프닝 안내 문구를 제안했고, 이후 마지막 요청에서 실제 기능 추가를 다시 요청했습니다. 최종 답변에서 뮤 보상 기능을 반영했다고 안내했습니다.

오프닝 음성으로 제안된 문구:
> “포켓몬 인형 여섯 종류를 모두 모아 봐! 전부 모으면 특별한 뮤 인형을 선물로 줄게!”

**이 문구의 실제 음성 적용은 확인되지 않았습니다.** 수집 보상 기능과 오프닝 음성은 별개 항목입니다.

### 5.3 조작부 위치 변경 — 반영 안내

- 조이스틱과 집게 버튼을 **인형뽑기 기계 유리 바로 아래**로 올림.
- 왼쪽 조이스틱, 오른쪽 집게 버튼.
- 안내문과 코인·지폐 투입 영역은 조작부 아래에 배치한다고 안내.
- 기존 인형 외형과 게임 기능 유지.

### 5.4 인형 출구 아래 검정색 통 제거 — 반영 안내

- 출구 아래로 튀어나온 **검정색 통 장식만 제거**.
- 출구 자체와 인형 수령·보관 기능은 유지.
- 트레이 기능 자체를 삭제하라는 요청이 아니므로 구분 필요.

### 5.5 성공 난이도 표시창 크기 고정 — 반영 안내

- 난이도 선택이나 진행 상태 문구가 바뀌어도 창이 커지거나 줄어들지 않도록 수정.
- 상·중·하 선택 및 진행 중 표시 변경으로 주변 배치가 밀리지 않아야 함.
- PC·모바일 각각 같은 화면 폭에서 상태 변화에 따른 크기 변동을 막는 것이 목적. 모든 기기에서 같은 절대 픽셀 크기를 강제한다는 뜻은 아님.
- 정확한 CSS 치수는 다음 소스 확인 시 기록.

### 5.6 떨어진 위치 유지·쌓기·위쪽 우선 집기 — 반영 안내

- 운반 중 떨어진 인형은 **낙하한 위치에 남음**.
- 같은 자리에 다른 인형이 있으면 그 위에 쌓임.
- 쌓인 인형은 **맨 위 인형부터 집을 수 있음**.
- 집게 하강 높이도 쌓인 높이에 맞추도록 조정했다고 안내.
- 단순한 화면 가림 순서만이 아니라 집기 대상 판정과 집게 정지 높이가 함께 일치해야 함.

### 5.7 큰 갈고리 집게·사실적인 동작·잡힌 인형 정렬 — 최종 반영 안내

**사용자 요청:** 인형보다 더 큰 갈고리 모양 집게, 사실적인 집기 동작, 상승할 때 인형이 집게 위쪽보다 올라가지 않도록 정렬.

최종 답변에서 안내한 변경:
- 큰 인형도 감쌀 수 있는 **확대된 3발 금속 갈고리 집게**.
- **감속 하강 → 인형을 감싸며 닫힘 → 잠깐 멈춤 → 천천히 상승**.
- 잡힌 인형의 상단이 집게 헤드 위로 튀어나오지 않도록 위치·크기 계산 보정.
- 낙하 위치 유지, 인형 쌓기, 맨 위부터 집기 기능 유지.

### 5.8 뮤 특별 보상 — 최종 반영 안내

- 크기에 관계없이 **일반 포켓몬 6종을 각각 1개 이상 보관함에 수집**하면 달성.
- 같은 종류 인형 6개가 아니라 서로 다른 6종을 모아야 함.
- 기존 인형을 소비하지 않고 **뮤 인형 추가 지급**.
- **새 게임당 최초 완성 시 한 번만** 지급한다고 안내.
- 보관함에 **수집 현황 0/6** 표시.
- 사용자 핵심 요청은 ‘6종 수집 시 좋은 포켓몬 선물’이며, 뮤 확정·보관함 기준·크기 무관·새 게임당 1회는 이전 답변에서 제시하고 반영했다고 안내한 세부 정책입니다.

### 6.2 조작

- ↑ 안쪽: 사용자에게서 멀어지는 방향.
- ↓ 바깥쪽: 사용자에게 가까워지는 방향.
- ← / → 좌우 이동.
- 표시 문구는 혼동되는 ‘앞/뒤’보다 ‘안쪽/바깥쪽’ 사용.
- 빨간 손잡이와 금속봉이 있는 오락실 조이스틱 형태.
- 마우스·터치 드래그와 키보드 방향키에 기울기 연동.
- 대각선 입력 및 누르고 있는 동안 부드러운 연속 이동.
- 입력을 놓으면 중립으로 복귀, 창 이탈 시 이동 중지.
- 집게 작동은 화면 버튼 또는 Space가 기존 기준. Enter 지원 여부는 소스 확인.
- 집게 작동·복귀 중과 오프닝 중에는 사용자 조작 제한.
- 과거 손잡이 크기 안내는 PC 70px / 모바일 66px이나 현재 CSS 값은 미재검증.

### 6.3 크레인·집게·공간 좌표

- 시작 및 새 게임 시 집게는 출구 위에 위치.
- 대기·수평 이동 중에는 줄을 짧게 감음.
- 집게 버튼을 눌러야 줄이 풀리며 하강.
- 천장 레일, 앞뒤 가로빔, 좌우 이동 장치, 케이블, 집게가 연결된 모습 유지.
- 집게는 인형 높이 또는 더미 최상단 높이에 맞춰 감속·정지.
- 확대된 금속 갈고리가 인형을 감싼 뒤 닫히고, 잠시 멈춘 후 함께 천천히 상승.
- 출구로 천천히 운반. 성공·헛집기·운반 중 낙하 모두 최종 복귀.
- 잡힌 인형 상단은 집게 헤드 위로 튀어나오지 않음.
- 집게 실제 접점, 바닥 그림자, 인형 중심, 출구 위치가 같은 좌표 체계를 사용해야 함.
- 집게 그림자는 바닥의 낙하/착지 기준점을 따름. 높이에 따라 크기·선명도는 달라져도 불필요하게 중심이 이동하지 않음.
- **반복 지적 문제:** 집게가 그림자보다 화면 앞쪽에 보임. CSS로 외형 위치만 옮겨 판정과 어긋나게 하지 말 것.
- 앞줄·모서리 및 낙하 후 위치의 인형에도 집게가 도달해야 함.

### 6.4 성공·실패·낙하·쌓기

- 잡기에 성공해도 운반 중 미끄러져 떨어질 수 있음.
- 중간 낙하는 실패이며 코인 보상 없음.
- 낙하 인형은 원래 자리로 돌아가지 않고 낙하 위치에 남아 재도전 가능.
- 낙하 위치에 인형이 있으면 위에 쌓이고, 아래 인형을 관통해 먼저 집지 않음.
- 더미 높이, 집기 우선순위, 화면 가림 순서가 일치해야 함.
- 근처에서 헛집으면 가까운 인형이 약 0.8초 흔들리는 과거 변경 기록이 있음. 멀리 빗나간 경우에는 흔들지 않음.
- 위 인형을 제거한 뒤 남은 더미 재정렬, 여러 지지 인형에 걸친 낙하, 최대 적재 높이 등은 현재 구현을 확인해야 하는 세부 항목임.

### 6.5 출구·트레이·보관함

- 출구는 초기 집게 위치의 바닥 그림자 아래에 맞춤.
- 출구 테두리·내부 깊이 표현은 유지하되 오늘 제거한 검정색 통 장식은 복원하지 않음.
- 출구로 배출된 인형은 수령 트레이에 모임.
- 트레이의 인형을 클릭·터치하면 보관함으로 이동.
- 기계 안의 인형을 직접 터치해 무료 획득하는 기능은 아님.
- 보관함은 종류별 보유 수량을 ×N으로 표시, 미획득은 ×0.
- 일반 성공 코인 보상은 트레이 도착 시 1회. 보관함 이동 시 다시 지급하지 않음.
- 뮤 보상 판정은 일반 6종의 보관함 수집을 기준으로 안내됨.

### 6.6 코인·지폐·플레이 횟수

| 동작 | 자원 변화 | 플레이 횟수 변화 |
|---|---|---|
| 코인 1개 투입 | 코인 -1 | +1회 |
| 지폐 1장 투입 | 지폐 -1, 코인 변화 없음 | +2회 |
| 작은 인형 성공 배출 | 코인 +3, 인형 트레이 이동 | 직접 충전 없음 |
| 큰 인형 성공 배출 | 코인 +6, 인형 트레이 이동 | 직접 충전 없음 |
| 헛집기 / 운반 중 낙하 | 성공 보상 없음 | 이미 사용한 판의 실패 |
| 트레이 → 보관함 | 보관 수량 증가, 코인 추가 없음 | 변화 없음 |

- 오늘 대화에서 업로드 파일의 초기 자원은 **코인 12개·지폐 5장**으로 안내됨. 최신 파일에서도 유지되는지 확인 필요.
- 코인 1개 = 1판 / 지폐 1장 = 2판 규칙 유지.
- **폐기된 규칙: 지폐 1장 = 코인 5개. 다시 도입하지 말 것.**
- 지폐가 0장이면 지폐 투입 버튼 비활성화.
- 돈이 남아 있고 충전된 횟수만 0이면 게임 종료가 아니라 투입 안내.
- 새 게임 시 지폐 5장 복원 안내 이력. 코인·보관함·트레이·뮤 지급 플래그 등 전체 리셋은 최신 소스로 확인.

### 6.7 난이도와 표시창

| 난이도 | 잡기 경향 | 잡은 뒤 운반 중 낙하 확률 |
|---|---|---:|
| 상 | 어려움 | 32% |
| 중 | 보통 / 기본값 | 23% |
| 하 | 쉬움 | 14% |

- 위 확률은 전체 실패율이나 최종 성공률이 아님.
- 조준이 정확할수록 유리하며 큰 인형은 같은 조건에서 작은 인형보다 잡기 어려운 기준.
- 정확한 기본 잡기 확률·조준 보정 공식은 소스 확인 필요.
- 작동 중 난이도 변경 금지.
- 난이도 변경으로 돈·횟수·보관함 등 진행 상태 초기화 금지.
- 난이도나 상태 문구 변경으로 성공 난이도 창 크기와 주변 배치가 변하지 않아야 함.

### 6.8 자동 리필과 뮤 지급 횟수

- 기계 안 인형을 전부 뽑고 마지막 배출·집게 복귀가 끝나면 40개 자동 리필.
- 작은 26개·큰 14개를 다시 섞어 배치.
- 코인·지폐·남은 횟수·보관함·트레이는 보존.
- 중간 낙하로 기계 안에 남은 인형은 소진으로 계산하지 않음.
- 뮤는 새 게임당 1회라는 안내 기준이므로 **자동 리필 때 뮤 지급 플래그가 초기화되면 안 됨**. 이는 다음 검증 항목임.
- 뮤를 일반 6종 수집 분모에 넣어 7종 완성을 요구하지 않음.

### 6.9 오프닝

- 이번 대화에서 등장 인물을 **한지우**로 정리했음. 포켓몬 GO 남자 트레이너로 임의 교체하지 않음.
- 순서: 등장 → 돈 투입 → 조작 → 피카츄 집기 → 상승·운반 → 출구 낙하 → 트레이 수령 → 품에 안고 퇴장 → 사용자 차례.
- 퇴장할 때 인형이 손·팔·몸과 함께 움직여야 하며 분리되어 남지 않아야 함.
- 얼굴·인체 비율·손가락·옷 주름·명암·걷기·몸 숙이기·안기 등 자연스러움이 주요 요구.
- 약 25초로 안내된 이력은 있으나 현재 길이는 확인 필요.
- 건너뛰기 버튼과 Esc 지원이 기존 기준.
- 실제 코인·지폐·인형 수량·성공 보상과 분리된 시연.
- **오늘의 자막 → 소리 요청은 미완료로 관리.** 실제 수집 보상이 반영되었다고 해서 음성까지 구현되었다고 간주하지 말 것.

### 8.1 기준 파일·화면

### 8.2 집게와 쌓기
- [ ] 작은 인형과 큰 인형을 감쌀 만큼 집게가 크게 보이는지 확인.
- [ ] 열림 → 감속 하강 → 감싸며 닫힘 → 멈춤 → 상승 동작 확인.
- [ ] 잡힌 인형 상단이 집게 헤드 위로 올라가지 않는지 확인.
- [ ] 앞·중간·뒤·양끝에서 접점·그림자·인형 중심 정합성 확인.
- [ ] 빈 바닥 낙하 시 그 위치에 남고 재집기가 가능한지 확인.
- [ ] 다른 인형 위 낙하 시 겹쳐 관통하지 않고 쌓이는지 확인.
- [ ] 2단 이상 더미에서 위 인형만 집히며 그 높이에서 하강을 멈추는지 확인.
- [ ] 위 인형을 제거한 뒤 아래 인형을 정상적으로 집을 수 있는지 확인.
- [ ] 천장 부근 적재, 경계 낙하, 여러 인형 위에 걸친 낙하 확인.
- [ ] 성공·실패·헛집기 모두 집게가 복귀하고 다음 판 조작 가능 확인.

### 8.3 경제·수집 보상
- [ ] 작은 성공 +3코인 / 큰 성공 +6코인 / 실패 0코인 확인.
- [ ] 트레이 터치 시 보관 수량만 늘고 코인 중복 지급 없음 확인.
- [ ] 코인 1개 +1판, 지폐 1장 +2판이며 지폐가 코인으로 바뀌지 않음 확인.
- [ ] 같은 종류 여러 개는 수집 종류 수를 늘리지 않음 확인.
- [ ] 작은/큰 인형을 섞어도 서로 다른 일반 6종이면 달성 확인.
- [ ] 5종 보관 + 마지막 종 트레이 대기 때 지급되지 않고 보관 후 지급되는지 확인.
- [ ] 일반 6종은 그대로 남고 뮤가 정확히 1개 지급되는지 확인.
- [ ] 연속 클릭·추가 획득·난이도 변경·자동 리필로 뮤 중복 지급 없음 확인.
- [ ] 새 게임 시 수집 현황과 뮤 지급 상태가 의도대로 초기화되는지 확인.
- [ ] 뮤 수령 방식·표시·추가 코인 보상 유무는 코드 확인 후 기록. 미확정 사항을 임의로 추가하지 않음.

### 8.4 리필·리셋·입력·오프닝
- [ ] 전체 소진 시 마지막 배출·복귀 후 40개를 한 번만 리필.
