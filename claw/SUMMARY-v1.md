# 포켓몬 인형뽑기 (claw) — 전체 작업 정리 v1

> 누적 인수인계 문서. 이전 SUMMARY.md(어제·오늘 웹 버전 이력) + 이번 안드로이드 PWA 재작성 작업을 통합했습니다.
> **기준 파일: `claw-v1.html`** (단일 파일, 이 문서와 함께 보관·첨부)
> 파일 명명 규칙: 게임 파일 `claw-v{N}.html`, 요약 `SUMMARY-v{N}.md`. 다음 수정은 v2.

---

## 1. 이 문서 사용법

- 다음 작업은 반드시 `claw-v1.html`에서 이어갑니다. 이전 웹 버전 HTML(어제 난이도 버전 등)로 돌아가지 마세요.
- `claw-v1.html`은 **처음부터 다시 작성한 코드**입니다. 이전 웹 버전의 코드를 그대로 가져온 것이 아니라, 이전 SUMMARY.md의 규칙·수치·방향을 기준으로 모바일(안드로이드 세로 화면)용으로 새로 구현했습니다.
- 이전 웹 버전 HTML 파일들은 이번 대화에서 접근할 수 없었으므로(링크 만료) 외형·세부 동작이 완전히 같지는 않습니다. 규칙(경제·수량·난이도·보상·조작 방향)은 이전 문서 기준을 모두 유지했습니다.
- 이 문서의 "검증" 항목은 실제로 수행한 범위만 적었습니다. 실제 안드로이드 기기 터치 플레이는 아직 하지 않았습니다.

## 2. 파일 구성

| 파일 | 내용 |
|---|---|
| `claw-v1.html` | 게임 전체(단일 파일). 폰에 보내 Chrome으로 열면 바로 동작 |
| `pokeclaw-pwa-1.zip` | PWA 패키지: index.html(=claw-v1.html) + manifest.webmanifest + sw.js + 아이콘 3종 + README.md |
| `SUMMARY-v1.md` | 이 문서 |

### 안드로이드 설치 방법 (PWA)
1. zip을 풀어 폴더째 HTTPS 정적 호스팅에 업로드 (GitHub Pages, Netlify Drop 등).
2. 안드로이드 **Chrome**으로 접속 → 화면 아래 "📲 홈 화면에 앱으로 설치" 버튼 또는 ⋮ 메뉴 > 앱 설치.
3. 홈 화면 아이콘 실행 → 전체화면·세로 고정·오프라인 동작.
- 호스팅 없이 `claw-v1.html` 하나만 열어도 게임은 전부 동작(설치·오프라인 캐시만 제외).
- 삼성 인터넷은 한국어 TTS가 없을 수 있어 Chrome 권장.

## 3. 게임 방향 (유지)

- 단일 HTML, Canvas 2D 기반 **2.5D 인형뽑기**. 원근·깊이·그림자·가림 순서로 공간감 표현.
- 모바일 세로 화면 우선(최대 폭 520px), PC 키보드·마우스도 지원.
- 포켓몬 인형 외형은 Canvas 벡터 드로잉(이미지 파일 없음).
- 새 기능 추가 시 코인·지폐·트레이·보관함·난이도·리필·뮤 규칙을 보존.

## 4. 누적 작업 이력

### 4.1 어제까지 (이전 웹 버전, SUMMARY.md 기준)
1. 조작 방향 정리(↑안쪽/↓바깥쪽), 모바일 판정, 종료 안내, 획득 표시 개선.
2. 집게·그림자·착지점 좌표 정합성 반복 개선.
3. 포켓몬 인형 6종 외형, 인형 확대, 코인 투입구, 금속 3발 집게, 빨간 조이스틱.
4. 인형 운반, 운반 중 낙하, 성공 코인 보상, 출구 복귀.
5. 2.5D 공간감, 출구 깊이, 수령 트레이, 터치 보관, 종류별 수량 표시.
6. 지폐 1장 = 2판, 보유 지폐 표시.
7. 한지우 오프닝(등장→투입→조작→피카츄 집기→운반→출구→트레이→안고 퇴장).
8. 느린 하강·상승·운반, 작은/큰 인형 차등 보상.
9. 인형 18→28→40개, 실패 시 근처 인형 흔들림.
10. 줄 풀림·감김, 작은/큰 혼합 배치, 전체 소진 후 자동 리필.
11. 앞줄 접근 범위 수정, 난이도 상·중·하.

### 4.2 어제 "오늘" 작업 (이전 웹 버전)
- 조이스틱·집게 버튼을 유리 바로 아래로 이동(왼쪽 조이스틱 / 오른쪽 버튼).
- 출구 아래 검정 통 장식 제거(출구·트레이 기능 유지).
- 난이도 표시창 크기 고정.
- 낙하 위치 유지·인형 쌓기·맨 위부터 집기.
- 대형 갈고리 집게, 사실적 집기 동작, 잡힌 인형 상단 정렬.
- 6종 수집 시 뮤 보상(새 게임당 1회).
- **미완료였던 항목:** 오프닝 자막 → 소리.

### 4.3 이번 작업 (claw-v1.html, 안드로이드 PWA)

**A. 모바일용 전면 재작성**
- 세로 레이아웃: 헤더(코인·지폐·남은 판) → 기계 캔버스(62vh, 최대 560px) → 조작부(왼쪽 조이스틱 132px·오른쪽 집게 버튼 118px) → 상태창(높이 44px 고정) → 투입 버튼 → 난이도창(높이 52px 고정) → 트레이 → 보관함 → 기타 버튼.
- 월드 좌표계: x ∈ [-100,100](좌→우), z ∈ [0,100](바깥쪽→안쪽), y = 높이. 집게·그림자·인형·출구가 같은 좌표계(`proj(x,z,y)`) 사용.
- 터치 조이스틱(pointer capture, 데드존 15%, 대각선·연속 이동, 놓으면 중립), 키보드 방향키 + Space/Enter.
- PWA: manifest(fullscreen, portrait), service worker 오프라인 캐시, 설치 버튼(beforeinstallprompt), 아이콘 192/512/maskable.
- WebAudio 효과음(코인·지폐·버튼·집게 닫힘·상승·낙하·성공·실패·착지·보관·뮤 팡파레) + 소리 끄기 버튼.

**B. 이전 요구사항 반영 (모두 구현)**
- 일반 6종: 피카츄·이상해씨·파이리·꼬부기·푸린·잠만보 (이전 문서에서 마스킹되어 재확인 불가했던 목록을 이번에 확정). 특별 보상: 뮤.
- 40개(작은 26 / 큰 14), 큰 인형 반지름 12.2 vs 작은 9 (≈1.35배). 초기 배치는 겹치지 않게 완화(relaxation) 배치 후 바닥에 평평하게, 출구 주변은 비움.
- 대형 3발 갈고리 집게: 열림 → 감속 하강 → 0.7초 감싸며 닫힘 → 0.5초 멈춤 → 천천히 상승 → 출구로 운반 → 열림/배출 → 복귀. 잡힌 인형 상단 = 집게 헤드 바닥(절대 헤드 위로 안 올라감).
- 집게 그림자는 바닥 기준점(x,z)에 고정, 높이에 따라 크기·투명도만 변화.
- 낙하 위치 유지·쌓기·맨 위부터 집기(`settle`, `pickTarget`): 겹침 판정 거리 (r1+r2)×0.6, 아래 인형 관통 금지, 더미 높이에 맞춰 하강 정지.
- 헛집기 시 반경 2.6r 안 인형 0.8초 흔들림.
- 유리 아래 조작부, 검정 통 없음(출구 테두리+내부 깊이만), 난이도창·상태창 크기 고정.
- 뮤: 일반 6종이 **보관함**에 각 1개 이상이면 즉시 1개 지급(새 게임당 1회, 리필·추가 보관으로 중복 없음). 보관함에 "수집 N/6" 표시.
- 한지우 오프닝(약 25~30초, Canvas 드로잉): 등장→투입 설명→조이스틱 이동→집기→운반→트레이→허리 숙여 집기→피카츄 안고 퇴장. 건너뛰기 버튼·Esc. 시연은 실제 자원·뮤 판정에 영향 없음.

**C. 이번에 새로 추가**
1. **오프닝 소리 (미완료 항목 해결)** — 첫 화면 "🔊 소리 켜고 시작" 버튼(모바일 자동재생 제한 대응) → 한지우 대사 7마디를 Web Speech API 한국어 음성으로 읽음. 자막은 유지. 건너뛰기·Esc·화면 꺼짐·소리 끄기 시 음성 중단. 한국어 음성이 없는 기기는 자막만.
2. **자동 저장/이어하기 (localStorage)** — 코인·지폐·남은 판·난이도·소리 설정·기계 안 인형(종류·크기·위치·쌓인 높이)·트레이·보관함·뮤 지급 여부. 투입·판 종료·보관·난이도 변경·화면 꺼짐 시 저장. 재실행 시 "▶ 이어하기". "새 게임"은 저장 삭제.
3. **오프닝 다시 보기 복원** — 진행 중 오프닝을 다시 봐도 끝나면 기계·트레이·자원이 원래대로 복원(이전엔 리필돼 버림).
4. **진동 피드백** — 투입·잡기·실패·낙하·성공·뮤 패턴. 소리 끄면 진동도 꺼짐.
5. 당겨서 새로고침 방지, 창 이탈·화면 꺼짐 시 조작 중지.

## 5. 현재 규칙·수치 명세 (claw-v1.html 소스 기준)

### 5.1 경제
| 동작 | 자원 | 판 수 |
|---|---|---|
| 시작 | 코인 12, 지폐 5 | 0 |
| 코인 1개 투입 | 코인 −1 | +1 |
| 지폐 1장 투입 | 지폐 −1 (코인 변화 없음) | +2 |
| 작은 인형 트레이 도착 | 코인 +3 | — |
| 큰 인형 트레이 도착 | 코인 +6 | — |
| 헛집기 / 운반 중 낙하 | 0 | 사용한 판 소모 |
| 트레이 → 보관함 | 보관 수량 +1, 코인 없음 | — |
- 지폐 0장이면 지폐 버튼 비활성. 판 0·돈 있음 → 투입 안내. 돈·판 모두 0 → 새 게임 안내.
- 폐기 규칙(지폐=코인 5개) 미도입.

### 5.2 난이도
| 난이도 | 기본 잡기 확률 base | 운반 중 낙하 |
|---|---|---|
| 상 | 0.42 | 32% |
| 중(기본) | 0.58 | 23% |
| 하 | 0.74 | 14% |
- 잡기 확률 = clamp(base × (큰 인형이면 0.78) × (0.35 + 0.65 × 조준정확도), 0.05, 0.97). 조준정확도 = 1 − 거리/(1.55r).
- 낙하는 운반 경로 15~85% 지점에서 발생. 작동 중·오프닝 중 난이도 변경 불가, 변경해도 진행 상태 유지.

### 5.3 집게·좌표
- 수평 이동 높이 92, 천장 118, 갈고리 길이 19, 이동 속도 46/초. 이동 범위 x ±86, z 10~92.
- 집기 판정: 집게 중심에서 반지름 대비 거리(d/r) < 1.55 인 가장 가까운 인형 → 그 위에 쌓인 인형이 있으면 맨 위로 올라감.
- 하강 정지 높이 = 대상 상단 + 갈고리 길이×0.55.
- 시작·복귀 위치 = 출구 위 (x −72, z 14, 반지름 17).

### 5.4 리필
- 기계 안 인형 0개 + 낙하/배출 애니메이션 종료 시 40개 리필(작은 26/큰 14 재배치). 돈·판·트레이·보관함·뮤 플래그 보존.

### 5.5 오프닝 대사 (음성+자막)
1. 안녕! 나는 한지우! 인형뽑기 하는 법을 보여줄게.
2. 코인 1개는 1판, 지폐 1장은 2판이야!
3. 조이스틱으로 움직여! ▲는 안쪽, ▼는 바깥쪽이야.
4. 집게 버튼을 누르면 내려가서 꽉 잡아!
5. 천천히 출구까지 운반… 가끔은 미끄러져 떨어질 수도 있어!
6. 트레이에 나온 인형을 터치하면 보관함에 들어가!
7. 여섯 종류를 전부 모으면 특별한 뮤 인형을 선물로 줄게!
8. 이제 네 차례야! 행운을 빌어!
