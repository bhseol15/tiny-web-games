## 3. 게임의 전체 방향 (보존 규칙)

- 브라우저에서 구동되는 **단일 HTML 기반 Canvas 2D 2.5D 인형뽑기 게임**. 원근감, 깊이, 바닥 그림자, 레이어 가림 순서로 공간감 표현.
- 모바일 세로 화면 우선 (최대 폭 520px 반응형) 및 PC 키보드(방향키, Space/Enter)·마우스 드래그 지원.
- 포켓몬 인형 외형은 Canvas 벡터 드로잉(외부 이미지 파일 의존성 없음).
- 코인, 지폐, 트레이, 보관함, 난이도, 자동 리필, 6종 수집 시 뮤 보상 규칙 보존.

## 4. 누적 작업 이력

### 4.1 초기 웹 버전 이력 (SUMMARY.md 기준)
1. 조작 방향 정리 (▲ 안쪽 = 원거리 / ▼ 바깥쪽 = 근거리), 모바일 판정, 획득 표시 개선.
2. 집게, 바닥 그림자, 착지점 좌표 정합성 개선.
3. 포켓몬 인형 6종 외형 디자인, 코인 투입구, 금속 3발 집게, 빨간 조이스틱 도입.
4. 인형 운반, 운반 중 낙하, 성공 시 코인 보상, 출구 복귀.
5. 출구 깊이 표현, 수령 트레이, 터치 시 보관함 이동, 종류별 수량(×N) 표시.
6. 지폐 1장 = 2판 규칙 정리 (코인으로 직접 환전되지 않음).
7. 한지우 등장 오프닝 연출 도입.
8. 작은 인형(+3코인) / 큰 인형(+6코인) 구분 및 차등 보상.
9. 인형 40개 배치, 헛집기 시 근처 인형 흔들림 효과.
10. 작은/큰 인형 혼합 배치, 기계 내 인형 전체 소진 시 자동 40개 리필.
11. 성공 난이도 상·중·하 선택창 추가.
12. 조이스틱·집게 버튼을 유리 바로 아래로 이동, 검정 통 장식 제거, 난이도창 크기 고정.
13. 운반 중 떨어진 인형 낙하 위치 유지 & 스택(쌓기) & 맨 위 인형 우선 집기.
14. 대형 3발 갈고리 집게 확대 및 잡힌 인형 상단 정렬.
15. 일반 6종 보관 시 특별 보상 **뮤** 1회 지급.

### 4.2 v1 작업 이력 (claw-v1.html, 모바일 PWA 재작성)
- 모바일 세로 화면에 최적화된 레이아웃 및 2.5D 월드 좌표계(`proj(x, z, y)`) 전면 재구축.
- 터치 조이스틱(포인터 캡처, 데드존 15%, 중립 자동 복귀) 및 키보드 연동.
- WebAudio 기반 다양한 효과음(코인, 지폐, 집게 닫힘, 상승, 낙하, 성공, 보관, 뮤 팡파레) 및 소리 토글.
- Web Speech API를 통한 한지우 한국어 TTS 음성 오프닝 시연 최초 도입.
- `localStorage` 기반 자동 저장 및 이어하기 기능 (`pokeclaw-save-v1`).
- PWA manifest 및 서비스 워커 설치 지원.

## 5. 오늘 작업 이력 (v2: 오프닝 음성 말 끊김 해결)

### 5.1 문제 원인 정밀 분석
1. **애니메이션 phase 전환 타이머가 대사 낭독 시간보다 짧아 강제 cancel 발생**:
   - `case 1`("코인 1개는 1판, 지폐 1장은 2판이야!") 낭독에 약 3초가 걸리는데, 타이머가 `d.t > 2.2초`로 설정되어 문장이 끝나기도 전에 phase 2로 넘어가며 `TTS.say`의 `speechSynthesis.cancel()`이 호출되어 말이 뚝 끊김.
   - `case 2`("조이스틱으로 움직여! ▲는 안쪽, ▼는 바깥쪽이야.")에서 크레인이 피카츄 좌표에 닿자마자 `d.t > 0.4초` 만에 phase 3으로 점프하여 긴 대사가 초반에 잘림.
   - `case 4`에서 집게가 올라와 운반(`carry`)을 시작할 때 중간에 캡션이 바뀌며 `TTS.say`가 호출되어 기존 발화를 끊음.
   - `case 5`("트레이에 나온 인형을 터치하면 보관함에 들어가!")는 약 3초가 걸리는데 1.6초 만에 phase 6으로 전환되어 잘림.
2. **브라우저 Web Speech API(Chrome/Android) 가비지 컬렉션(GC) 버그**:
   - `SpeechSynthesisUtterance` 객체가 로컬 변수에만 머무를 경우, 긴 문장을 말하는 도중 GC에 의해 수거되어 중간에 갑자기 무음으로 끊기는 브라우저 고유 버그 존재.
3. **특수문자 및 숫자 발음 부자연스러움**:
   - `▲`, `▼`, `1개는 1판`, `1장은 2판` 등의 기호가 음성 합성기에서 부자연스럽게 처리되거나 끊기는 요인으로 작용.

### 5.2 v2 적용 및 해결 내용
1. **TTS 엔진 고도화 (`TTS`)**:
   - **GC 방지 전역 참조**: `TTS._curr = u;` 및 발화 종료 시 해제 처리로 재생 중 무음 끊김 예방.
   - **이벤트 콜백 & 완료 감지**: `u.onend`, `u.onerror` 핸들러를 등록하고 `TTS.say(text, onEnd)` 구조로 개편.
   - **안전 타임아웃 백업**: 모바일 브라우저 등에서 간혹 `onend` 이벤트가 누락되는 경우를 대비해 글자 수 비례 안전 타이머(`clean.length * 130ms + 1200ms`)를 두어 멈춤 현상 완벽 방지.
   - **자연스러운 한국어 발음 치환**:
     - `▲` → "위쪽은", `▼` → "아래쪽은", `1개는 1판` → "한 개는 한 판", `1장은 2판` → "한 장은 두 판" 등 또렷하고 자연스럽게 발음되도록 사전 전처리.
   - **크롬 발화 멈춤 킵얼라이브**: 긴 세션 중 브라우저 음성 엔진 멈춤 방지를 위한 `pause/resume` 킵얼라이브 등록.
2. **오프닝 단계(Phase) 상태 머신 전면 개편 (`setDemoPhase`, `updateDemo`)**:
   - 단계 전환 함수 `setDemoPhase(phase)`를 통해 각 단계 진입 시 대사를 **정확히 한 번** 발화하고 `speechDone = false` 설정.
   - 각 단계 전환 조건을 **[모션 액션 완료] + [대사 낭독 완료(`speechDone`)] + [자연스러운 여유 시간]**을 모두 만족할 때만 다음 단계로 넘어가도록 재설계:
     - **Phase 0 (등장)**: 지우 걸어 들어옴 + 인사 대사 완료 후 Phase 1 진입.
     - **Phase 1 (투입)**: 코인 투입 제스처 및 코인 효과음 + 투입 안내 대사 끝까지 낭독 후 Phase 2 진입.
     - **Phase 2 (조작/조준)**: 조이스틱 이동으로 피카츄 위에 도착하더라도, "조이스틱으로 움직여! 위쪽은 안쪽, 아래쪽은 바깥쪽이야" 대사가 끝날 때까지 조준 자세를 유지하며 대기 후 Phase 3 진입.
     - **Phase 3 (집기)**: "집게 버튼을 누르면 내려가서 꽉 잡아!" 대사와 함께 집게 하강 → 닫힘 → 상승 완료 시 Phase 4 진입.
     - **Phase 4 (운반/낙하)**: "천천히 출구까지 운반해! 가끔은 미끄러져 떨어질 수도 있어" 대사가 온전히 나오며, 인형이 출구 구멍을 통해 트레이에 떨어지고 대사가 끝난 후 Phase 5 진입.
     - **Phase 5 (수령)**: 지우가 허리를 숙여 트레이에서 피카츄를 품에 안고 일어서며, "트레이에 나온 인형을 터치하면 보관함에 들어가!" 대사 끝까지 완료 후 Phase 6 진입.
     - **Phase 6 (뮤 안내)**: 피카츄를 품에 안은 채 "여섯 종류를 전부 모으면 특별한 뮤 인형을 선물로 줄게!" 대사 끝까지 완료 후 Phase 7 진입.
     - **Phase 7 (퇴장)**: "이제 네 차례야! 행운을 빌어!" 대사와 함께 오른쪽 화면 밖으로 당당하게 걸어서 퇴장한 뒤 본 게임 시작.
3. **세이브 호환성**:
   - `pokeclaw-save-v2`를 기본 키로 사용하며, 기존 `v1` 세이브 데이터가 있을 경우 자동으로 로드하여 이어하기 지원.
4. **허브 링크 갱신**:
   - 메인 `index.html`에서 Claw 카드의 링크를 `./claw/claw-v2.html`로 업데이트.

## 6. 현재 규칙·수치 명세 (`claw-v2.html` 소스 기준)

### 6.1 경제 시스템
| 동작 | 자원 변화 | 판 수 변화 |
|---|---|---|
| 게임 시작 | 코인 12개, 지폐 5장 | 0판 |
| 코인 1개 투입 | 코인 −1 | +1판 |
| 지폐 1장 투입 | 지폐 −1 (코인 변화 없음) | +2판 |
| 작은 인형 성공 배출 | 코인 +3 (트레이 도착 시) | 변화 없음 |
| 큰 인형 성공 배출 | 코인 +6 (트레이 도착 시) | 변화 없음 |
| 헛집기 / 중간 낙하 | 0 | 사용한 판 소모 |
| 트레이 → 보관함 터치 | 보관 수량 +1 (코인 추가 없음) | 변화 없음 |

### 6.2 인형 구성 및 배치
- **일반 6종**: 피카츄, 이상해씨, 파이리, 꼬부기, 푸린, 잠만보
- **특별 보상**: 뮤 (일반 6종을 보관함에 각 1개 이상 모으면 즉시 1개 선물 지급, "수집 N/6" 표시, 새 게임당 1회)
- **수량**: 총 40개 (작은 인형 26개, 큰 인형 14개)
- **크기**: 작은 인형 반지름 9, 큰 인형 반지름 12.2 (약 1.35배)
- **배치**: 출구 주변을 비우고 자연스러운 완화(relaxation) 배치 후 바닥 평평하게 정렬

### 6.3 난이도
| 난이도 | 기본 성공률 가중치 | 운반 중 낙하 확률 |
|---|---|---:|
| 상 | 어려움 (base 0.42) | 32% |
| 중 (기본값) | 보통 (base 0.58) | 23% |
| 하 | 쉬움 (base 0.74) | 14% |
