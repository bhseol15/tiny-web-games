## 3. 게임의 전체 방향 (보존 규칙)

- 브라우저에서 구동되는 **단일 HTML 기반 Canvas 2D 2.5D 인형뽑기 게임**. 원근감, 깊이, 바닥 그림자, 레이어 가림 순서로 공간감 표현.
- 모바일 세로 화면 우선 (최대 폭 520px 반응형) 및 PC 키보드(방향키, Space/Enter)·마우스 드래그 지원.
- 포켓몬 인형 외형은 Canvas 벡터 드로잉(외부 이미지 파일 의존성 없음).
- 코인, 지폐, 트레이, 보관함, 난이도, 자동 리필, 6종 수집 시 뮤 보상 규칙 보존.

## 4. 누적 작업 이력

### 4.1 초기 웹 버전 이력 (SUMMARY.md 기준)
1. 조작 방향 정리 (▲ 안쪽 = 원거리 / ▼ 바깥쪽 = 근거리), 모바일 판정, 획득 표시 개선.
2. 집게, 바닥 그림자, 착지점 좌표 정합성 개선.
3. 포켓몬 인형 6종 외형 디자인, 코인 투입구, 금속 3발 집게, 빨간 조이스틱 도입.
4. 인형 운반, 운반 중 낙하, 성공 시 코인 보상, 출구 복귀.
5. 출구 깊이 표현, 수령 트레이, 터치 시 보관함 이동, 종류별 수량(×N) 표시.
6. 지폐 1장 = 2판 규칙 정리 (코인으로 직접 환전되지 않음).
7. 한지우 등장 오프닝 연출 도입.
8. 작은 인형(+3코인) / 큰 인형(+6코인) 구분 및 차등 보상.
9. 인형 40개 배치, 헛집기 시 근처 인형 흔들림 효과.
10. 작은/큰 인형 혼합 배치, 기계 내 인형 전체 소진 시 자동 40개 리필.
11. 성공 난이도 상·중·하 선택창 추가.
12. 조이스틱·집게 버튼을 유리 바로 아래로 이동, 검정 통 장식 제거, 난이도창 크기 고정.
13. 운반 중 떨어진 인형 낙하 위치 유지 & 스택(쌓기) & 맨 위 인형 우선 집기.
14. 대형 3발 갈고리 집게 확대 및 잡힌 인형 상단 정렬.
15. 일반 6종 보관 시 특별 보상 **뮤** 1회 지급.

### 4.2 v1 작업 이력 (claw-v1.html, 모바일 PWA 재작성)
- 모바일 세로 화면에 최적화된 레이아웃 및 2.5D 월드 좌표계(`proj(x, z, y)`) 전면 재구축.
- 터치 조이스틱(포인터 캡처, 데드존 15%, 중립 자동 복귀) 및 키보드 연동.
- WebAudio 기반 다양한 효과음 및 소리 토글.
- Web Speech API를 통한 한지우 한국어 TTS 음성 오프닝 시연 최초 도입.
- `localStorage` 기반 자동 저장 및 이어하기 기능.

### 4.3 v2 작업 이력 (claw-v2.html, 오프닝 음성 말 끊김 해결)
- 대사 낭독 시간보다 짧았던 애니메이션 전환 타이머를 전면 재설계.
- `TTS._curr = u`로 브라우저 GC 무음 중단 버그 방지.
- `setDemoPhase` 상태 머신으로 [동작 완료] + [대사 완독(`speechDone`)] 동기화.
- 특수기호(`▲`, `▼`, `1개는 1판` 등)를 또렷한 한국어 발음으로 사전 치환.

### 4.4 v3 작업 이력 (claw-v3.html, 6종 변신 메타몽 및 미보유 변신)
- 기계 안 40개 인형 중 6종류 각각 1마리씩 총 6마리의 메타몽 버전(`ditto: true`) 숨기기.
- 각 포켓몬의 체형/디테일은 유지하고 눈과 입을 메타몽 특유의 앙증맞은 **점눈과 일자 미소 `( • _ • )`**로 렌더링.
- 메타몽 인형 배출 시 트레이에 보랏빛 아우라 및 `변신!` 뱃지 부착.
- 트레이 터치 시 보관함에 **아직 모으지 못한 포켓몬으로 즉시 변신**하여 수량 +1 추가.

## 5. 오늘 작업 이력 (v4: 메타몽 메가 집게 버프 & 2마리 동시 포획)

### 5.1 메타몽 획득 시 3판 메가 집게 버프 발동
- **발동 조건**:
  - 메타몽 인형(`p.ditto === true`)이 출구로 배출되어 수령 트레이에 도착했을 때 즉시 `S.dittoBuff += 3` 부여 (연속 획득 시 +3판씩 중첩).
  - 획득 즉시 `SFX.dittoFind()` 및 `SFX.megaClaw()` 아르페지오 사운드 재생 + 진동 피드백.
  - 토스트 알림: `🟣 메타몽 파워! 메가 집게 3판 발동!`
- **HUD 배너 (`#buffBanner`)**:
  - 게임 화면 상단에 보라색 네온 글로우 애니메이션 배너 노출.
  - `🟣 메타몽 메가 집게 발동 중! 남은 N판 · 집게 거대화 & 2마리 동시 포획!` 문구 및 실시간 잔여 판 수 표시.
- **판 소모 규칙**:
  - 집게를 내릴 때(`startGrab()`) 잔여 버프 판 수가 1씩 차감되며 이번 판에 `c.isBuff = true`가 적용됨.

### 5.2 집게 시각적 거대화 (`drawClaw`, `drawShadow`)
- **스케일**:
  - 버프 활성화 시 집게 헤드 및 3발 갈고리가 **1.45배 거대화** (`clawScale = 1.45`).
  - 갈고리 두께도 1.25배 두꺼워져 강력한 그립감 연출.
  - 바닥 그림자 크기도 1.4배 비례 확대되어 크레인의 접지감과 웅장함 유지.
- **메타몽 퍼플 메탈릭 스킨**:
  - 일반 금속 회색 대신, 신비로운 보라-마젠타 그라데이션(`hg: #7e22ce ~ #f5d0fe ~ #6b21a8`)과 보랏빛 보석 젬(`#e879f9`) 장착.
  - 갈고리에도 은은한 바이올렛 메탈 그라데이션이 적용되어 특수 버프 상태임을 시각적으로 명확히 전달.

### 5.3 한 번에 2개씩 동시 포획 시스템
- **2마리 동시 타겟팅 (`pickTarget`)**:
  - 집게 중심 유효 탐색 반경이 1.55배에서 **2.4배로 대폭 확장**.
  - 집게 아래 범위에 들어온 인형 중 거리 순 1위, 2위 최상단 인형 2개를 동시에 타겟팅 (`targets = [p1, p2]`).
  - 인형 더미(스택) 위에 올라가 있는 인형을 최우선으로 집는 기존 물리 규칙 완벽 보존.
- **잡기 성공률 및 안정성 보정 (`finishGrab`)**:
  - 메가 집게의 거대한 면적을 반영하여 각 인형의 기본 잡기 확률을 **+35% 상향 보정**.
  - 운반 중 미끄러져 떨어지는 낙하 확률을 **50% 감소**시켜 쾌감 극대화.
- **2마리 동시 운반 비주얼 (`updateClaw`, `drawScene`)**:
  - 2마리를 동시에 잡았을 때, 두 인형이 거대 집게 갈고리 좌우에 나란히 안착(`p1.x = c.x - 0.72*r`, `p2.x = c.x + 0.72*r`)하여 함께 상승 및 출구로 운반.
  - 2마리 포획 성공 시 전용 팡파레(`SFX.mew()`)와 함께 `🎉 대박! [포켓몬1] & [포켓몬2] 2마리를 동시에 잡았어요!` 상태창 알림 및 `🌟 2마리 동시 포획 성공! 🌟` 토스트 연출.
- **동시 배출 및 보상 (`updateFalls`)**:
  - 출구 구멍으로 2마리가 함께 떨어지며, 각각 수령 트레이에 독립적으로 추가.
  - 코인 보상도 2마리분(+3코인/+6코인) 모두 정상 중복 지급.

### 5.4 세이브 및 시스템 연동
- `SAVE_KEY = 'pokeclaw-save-v4'` 적용.
- `dittoBuff` 상태가 자동 저장되어 새로고침 후에도 남은 메가 집게 판 수가 그대로 유지됨.
- 이전 `v1`, `v2`, `v3` 세이브 데이터 완벽 하위 호환.
- 메인 허브 `index.html` 링크를 `claw-v4.html`로 업데이트 완료.

## 6. 현재 규칙·수치 명세 (`claw-v4.html` 소스 기준)

### 6.1 경제 시스템
| 동작 | 자원 변화 | 판 수 변화 |
|---|---|---|
| 게임 시작 | 코인 12개, 지폐 5장 | 0판 |
| 코인 1개 투입 | 코인 −1 | +1판 |
| 지폐 1장 투입 | 지폐 −1 (코인 변화 없음) | +2판 |
| 작은 인형 성공 배출 | 코인 +3 (트레이 도착 시) | 변화 없음 |
| 큰 인형 성공 배출 | 코인 +6 (트레이 도착 시) | 변화 없음 |
| 2마리 동시 성공 배출 | 코인 각각 합산 지급 (예: 소형+대형 시 +9코인) | 변화 없음 |
| **메타몽 인형 성공 배출** | 크기별 코인 지급 + **다음 3판간 메가 집게(2개 뽑기) 발동** | 변화 없음 |
| 헛집기 / 중간 낙하 | 0 | 사용한 판 소모 |
| 트레이 → 보관함 터치 | 일반: 해당 포켓몬 +1 / **메타몽: 미보유 포켓몬으로 변신 후 +1** | 변화 없음 |

### 6.2 인형 구성 및 배치
- **일반 6종**: 피카츄, 이상해씨, 파이리, 꼬부기, 푸린, 잠만보
- **숨겨진 메타몽**: 6종 각각 1마리씩 총 6마리 (점눈 `(•_•)` 얼굴)
- **특별 보상**: 뮤 (일반 6종을 보관함에 각 1개 이상 모으면 즉시 1개 선물 지급, "수집 N/6" 표시, 새 게임당 1회)
- **수량**: 총 40개 (작은 인형 26개, 큰 인형 14개)
- **크기**: 작은 인형 반지름 9, 큰 인형 반지름 12.2 (약 1.35배)
