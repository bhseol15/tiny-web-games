## 3. 핵심 복원 및 신규 기능 (v6)

### 3.1 사용자 피드백 반영: 원래 집게 모양 및 오프닝/새 게임 버튼 완벽 복원
1. **원래 3D 메탈 갈고리 집게 (`drawClaw`) 복원**:
   - 사다리꼴 금속 몸통 헤드 + 붉은 루비 젬 (`#d8233a`).
   - 3개의 3D 곡선 메탈 갈고리 발톱 (`arms = [{a:-1,depth:0.7},{a:0,depth:1.1},{a:1,depth:0.7}]`)과 관절 볼트, 메탈 하이라이트 그라데이션, 천장 연결 쇠줄 케이블 원형 100% 복원.
   - 메타몽 버프 시 1.45배 거대화 및 보랏빛 메탈 스킨과 퍼플 젬 장착 기능 유지.
2. **한지우 오프닝 시연 시스템 복원**:
   - 첫 시작 오버레이 (`#startOv`: `🔊 소리 켜고 시작` `#bStart`) 클릭 시 한지우가 등장하여 코인 투입, 조이스틱 조작, 집게 하강, 피카츄 잡기, 트레이 수령 시연 및 음성 낭독 (`setDemoPhase`, `updateDemo`, `drawDemo`).
   - 우측 상단 `건너뛰기 ✕` (`#skip`) 버튼 연동.
3. **하단 기능 버튼 복원**:
   - `▶ 오프닝 다시 보기` (`#bOpening`): 언제든 한지우의 시연과 꿀팁을 다시 볼 수 있음.
   - `새 게임` (`#bNew`): 코인·지폐·보관함을 초기화하고 처음부터 다시 도전할 수 있는 리셋 버튼.
   - `🔊 소리 켜짐/꺼짐` (`#bSound`): 오디오 토글.
4. **오프닝 대사 말 끊김 방지 및 완벽 싱크 제어 (긴급 패치)**:
   - **원인 분석**:
     - 기존 코드에서 각 페이즈별 강제 전환 타임아웃(`phaseT > 3.6s ~ 4.2s`)이 대사 발화 시간보다 훨씬 짧게 하드코딩되어, 음성이 끝나기 전에 다음 페이즈로 강제 전환되면서 `TTS.stop()`이 직전 대사를 중간에 싹둑 잘라먹는 현상 발생.
     - 4.5초마다 실행되던 브라우저 강제 pause/resume 인터벌이 Windows Chrome 등에서 음성 단어를 씹거나 음소거를 유발함.
   - **해결 내역**:
     - `updateDemo(dt)` 전이 조건을 `d.speechDone` 완료 우선으로 개편. Web Speech API가 발화 중(`TTS.isSpeaking()`)일 때는 절대로 다음 단계로 넘기지 않도록 방어.
     - 무음 모드 또는 브라우저 이벤트 누락 시를 위한 안전 대기 타임아웃을 글자 수에 비례하여 충분히 넉넉하게(`Math.max(7.5, len * 0.22 + 3.0)`) 설정.
     - 대사와 대사 사이에 `0.35s ~ 0.5s`의 자연스러운 숨고르기(호흡) 텀(`d.postT`)을 부여하여 대화 흐름이 매우 자연스러워짐.
     - `TTS` 객체에 `window.__ttsCurrentUtterance` GC 참조 고정 및 백그라운드 paused 복구 전용 로직 적용.

  - 2차 이후: 일반 인형을 트레이에서 보관함으로 옮길 때마다 `S.legendProgress`가 1씩 증가하여, 6개가 모이면 (`legendProgress >= 6`) 다음 전설 이벤트 발동.

### 3.3 5% 확률 엉킴 끈 2마리 동시 포획 시스템
- 일반 판(버프가 아닐 때)에서도 1마리 집기 성공 시 **5% 확률(`Math.random() < 0.05`)**로 근처 인형과 끈이 엉켜 함께 집힘 (`c.isLinked = true`).
- 2.5D Canvas 공간에 두 인형을 연결하는 **황금빛 점선 끈**과 중심부의 깜찍한 **빨간 리본 매듭** 렌더링.
- 출구로 2마리가 함께 떨어지며 트레이에 각각 등록 및 코인 2배 합산 지급.
