## 3. 게임의 전체 방향 (보존 규칙)

- 브라우저에서 구동되는 **단일 HTML 기반 Canvas 2D 2.5D 인형뽑기 게임**. 원근감, 깊이, 바닥 그림자, 레이어 가림 순서로 공간감 표현.
- 모바일 세로 화면 우선 (최대 폭 520px 반응형) 및 PC 키보드(방향키, Space/Enter)·마우스 드래그 지원.
- 포켓몬 인형 외형은 Canvas 벡터 드로잉(외부 이미지 파일 의존성 없음).
- 코인, 지폐, 트레이, 보관함, 난이도, 자동 리필, 6종 수집 시 뮤 보상 규칙 보존.

## 4. 누적 작업 이력

### 4.1 초기 웹 버전 이력 (SUMMARY.md 기준)
1. 조작 방향 정리 (▲ 안쪽 = 원거리 / ▼ 바깥쪽 = 근거리), 모바일 판정, 획득 표시 개선.
2. 집게, 바닥 그림자, 착지점 좌표 정합성 개선.
3. 포켓몬 인형 6종 외형 디자인, 코인 투입구, 금속 3발 집게, 빨간 조이스틱 도입.
4. 인형 운반, 운반 중 낙하, 성공 시 코인 보상, 출구 복귀.
5. 출구 깊이 표현, 수령 트레이, 터치 시 보관함 이동, 종류별 수량(×N) 표시.
6. 지폐 1장 = 2판 규칙 정리 (코인으로 직접 환전되지 않음).
7. 한지우 등장 오프닝 연출 도입.
8. 작은 인형(+3코인) / 큰 인형(+6코인) 구분 및 차등 보상.
9. 인형 40개 배치, 헛집기 시 근처 인형 흔들림 효과.
10. 작은/큰 인형 혼합 배치, 기계 내 인형 전체 소진 시 자동 40개 리필.
11. 성공 난이도 상·중·하 선택창 추가.
12. 조이스틱·집게 버튼을 유리 바로 아래로 이동, 검정 통 장식 제거, 난이도창 크기 고정.
13. 운반 중 떨어진 인형 낙하 위치 유지 & 스택(쌓기) & 맨 위 인형 우선 집기.
14. 대형 3발 갈고리 집게 확대 및 잡힌 인형 상단 정렬.
15. 일반 6종 보관 시 특별 보상 **뮤** 1회 지급.

### 4.2 v1 작업 이력 (claw-v1.html, 모바일 PWA 재작성)
- 모바일 세로 화면에 최적화된 레이아웃 및 2.5D 월드 좌표계(`proj(x, z, y)`) 전면 재구축.
- 터치 조이스틱(포인터 캡처, 데드존 15%, 중립 자동 복귀) 및 키보드 연동.
- WebAudio 기반 다양한 효과음 및 소리 토글.
- Web Speech API를 통한 한지우 한국어 TTS 음성 오프닝 시연 최초 도입.
- `localStorage` 기반 자동 저장 및 이어하기 기능 (`pokeclaw-save-v1`).
- PWA manifest 및 서비스 워커 설치 지원.

### 4.3 v2 작업 이력 (claw-v2.html, 오프닝 음성 말 끊김 해결)
- 대사 낭독 시간보다 짧았던 애니메이션 전환 타이머를 전면 재설계.
- `TTS._curr = u`로 브라우저(Chrome/Android) 가비지 컬렉션(GC) 무음 중단 버그 방지.
- `setDemoPhase` 상태 머신으로 [동작 완료] + [대사 완독(`speechDone`)] 동기화.
- 특수기호(`▲`, `▼`, `1개는 1판` 등)를 또렷한 한국어 발음으로 사전 치환.
- `pokeclaw-save-v2` 세이브 및 이전 버전 하위 호환.

## 5. 오늘 작업 이력 (v3: 6종 변신 메타몽 숨기기 및 변신 시스템)

### 5.1 6종 인형 메타몽 버전 숨기기
- **컨셉**: 포켓몬 공식 굿즈 시리즈인 **'변신! 메타몽(へんしん！メタモン)'**을 모티브로 적용.
- **배치**:
  - 기계 내 총 40개 인형 중 **일반 6종류 각각 1마리씩, 총 6마리의 메타몽 버전 인형**(`ditto: true`)이 무작위로 숨겨져 생성.
  - 작은 인형 26개, 큰 인형 14개 구조를 유지하면서 고르게 분배.
- **Canvas 드로잉 (`drawPlush`)**:
  - 각 포켓몬의 체형, 컬러, 귀, 꼬리, 등껍질 등 고유 특징은 그대로 유지하되,
  - `isDitto === true`인 경우 눈과 입을 메타몽 특유의 앙증맞은 **점눈과 일자 미소 `( • _ • )`**로 정밀 렌더링.
  - 플레이어가 기계 안을 유심히 관찰하면 "어? 이 피카츄 눈이 점눈이네!" 하고 찾아내는 재미 부여.

### 5.2 메타몽 획득 및 미보유 포켓몬 변신 시스템
1. **집게 운반 및 출구 배출**:
   - 집게에 잡혔을 때: `피카츄(메타몽!) 인형을 잡았어요! 출구로 운반 중…`
   - 출구로 떨어져 트레이에 도착했을 때:
     - `SFX.dittoFind()` 전용 발견 팡파레 효과음 재생.
     - 상태창: `작은 피카츄(변신 메타몽!) 획득! +3코인 · 트레이를 터치하면 없는 포켓몬으로 변신!`
     - 토스트 알림: `🟣 변신 메타몽 획득! +3코인`
2. **수령 트레이 UI (`renderTray`)**:
   - 메타몽 인형의 아이콘도 점눈 표정 그대로 캐시 생성.
   - 트레이 아이템에 보랏빛 신비로운 아우라 애니메이션(`.item.ditto { border-color: var(--ditto); animation: dittoGlow ... }`) 적용.
   - 왼쪽 상단에 보라색 그라데이션 **`변신!`** 뱃지 표시.
3. **보관함 이동 시 변신 로직 (`storeFromTray`)**:
   - 트레이의 메타몽 인형을 터치하면:
     - 현재 보관함에 **아직 모으지 못한(수량 0인) 일반 포켓몬 목록**(`missing`)을 탐색.
     - 아직 없는 포켓몬이 있다면 그중 하나를 무작위로 선택하여 변신!
     - 6종을 이미 다 모은 상태라면 현재 보유 수량이 가장 적은 포켓몬으로 변신.
     - 선택된 포켓몬의 보관 수량이 +1 증가.
   - **변신 연출**:
     - 신비로운 신디사이저 아르페지오 음향(`SFX.transform()`)과 풍부한 햅틱 진동 피드백.
     - 상태창 안내: `✨ 얍! 메타몽이 아직 없던 [포켓몬이름] 인형으로 변신했어요!`
     - 토스트 알림: `✨ 메타몽 변신 ➜ [포켓몬이름]! ✨`
     - 이 변신으로 6종이 모두 완성되면 특별 보상 **뮤** 팡파레가 즉시 발동!

### 5.3 세이브 및 시스템 연동
- `SAVE_KEY = 'pokeclaw-save-v3'` 적용.
- `tray` 및 `plushes` 저장 시 메타몽 플래그(`d: 1/0`)를 저장하여 새로고침 후에도 메타몽 상태가 유지됨.
- 기존 `v2`, `v1` 세이브 데이터 자동 마이그레이션 호환.
- 오프닝 시연에서 지우가 잡는 피카츄는 일반 피카츄(`!p.ditto`)로 고정하여 데모 안정성 보장.
- 하단 안내문에 메타몽 변신 규칙 명시.
- 메인 `index.html` 바로가기 링크를 `claw-v3.html`로 업데이트.

## 6. 현재 규칙·수치 명세 (`claw-v3.html` 소스 기준)

### 6.1 경제 시스템
| 동작 | 자원 변화 | 판 수 변화 |
|---|---|---|
| 게임 시작 | 코인 12개, 지폐 5장 | 0판 |
| 코인 1개 투입 | 코인 −1 | +1판 |
| 지폐 1장 투입 | 지폐 −1 (코인 변화 없음) | +2판 |
| 작은 인형 성공 배출 | 코인 +3 (트레이 도착 시) | 변화 없음 |
| 큰 인형 성공 배출 | 코인 +6 (트레이 도착 시) | 변화 없음 |
| 헛집기 / 중간 낙하 | 0 | 사용한 판 소모 |
| 트레이 → 보관함 터치 | 일반: 해당 포켓몬 +1 / **메타몽: 미보유 포켓몬으로 변신 후 +1** | 변화 없음 |

### 6.2 인형 구성 및 배치
- **일반 6종**: 피카츄, 이상해씨, 파이리, 꼬부기, 푸린, 잠만보
- **숨겨진 메타몽**: 6종 각각 1마리씩 총 6마리 (점눈 `(•_•)` 얼굴)
- **특별 보상**: 뮤 (일반 6종을 보관함에 각 1개 이상 모으면 즉시 1개 선물 지급, "수집 N/6" 표시, 새 게임당 1회)
- **수량**: 총 40개 (작은 인형 26개, 큰 인형 14개)
- **크기**: 작은 인형 반지름 9, 큰 인형 반지름 12.2 (약 1.35배)
- **배치**: 출구 주변을 비우고 자연스러운 완화(relaxation) 배치 후 바닥 평평하게 정렬
