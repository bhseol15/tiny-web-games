## 2. 구현 내용 (v1~v3.5 누적)

### 화면·조작
- 달걀 모양 기기 + 48×32 도트 LCD, 위아래 아이콘 8개(밥·간식·놀이·씻기·불·상태·도감·설정)
- 버튼 A(이동) / B(선택) / C(취소), 아이콘·메뉴 직접 터치 가능
- 키보드: ←→ 이동, Enter 선택, Esc 취소, Z/X/C = A/B/C
- 펫을 누르면 쓰다듬기(행복 +2), 알을 누르면 부화가 조금 빨라짐

### 오프닝
타이틀 → 문방구 컷신 → 이름 짓기(최대 6글자) → 속도 선택 → 시작

**문방구 컷신** — 주인공은 모자 쓴 초등학생 "잼민이" (v2, v3.2에서 물건 고르기 추가)

| 장면 | 내용 | 조작 |
|---|---|---|
| 1 | 잼민이가 용돈을 들고 문방구로 걸어감 | B 다음 / C 물건 고르기로 건너뛰기 |
| 2 | 가게 안, 주인이 "뭘 사러 왔니?" 하고 물음 | B 다음 / C 건너뛰기 |
| 3 | **간식 · 학용품 · 다마고치 중 고르기 (v3.2)** | A(←→) 이동, B 선택, C 뒤로, 물건을 직접 눌러도 됨 |
| 3-1 | 간식이나 학용품을 고르면 잼민이가 그 물건을 들고 "근데 다마고치는?" 하는 짧은 장면 | B → 다시 물건 고르기(다마고치에 커서) |
| 4 | 다마고치를 고르면 물·흙·하늘 알 3개 중 1개 고르기 | A(←→) 이동, B 선택, C 물건 고르기로, 알을 직접 눌러도 됨 |
| 5 | 잼민이가 동전을 내고 계산 | B 구매 / C 다시 고르기 |
| 6 | 구매 완료, 잼민이가 알을 들고 기뻐함 | B → 이름 짓기 |

- 처음 커서는 다마고치에 놓여 있음. 간식·학용품은 재미 장면만 있고 게임 수치에는 영향이 없음
- 가출 후 새 알을 고를 때와 "새 알로 다시 시작"에서도 같은 컷신이 나옴
- 이름 짓기에서 C를 누르면 알 고르기 장면으로 돌아감

### 돌봄 수치 (0~100)
- 포만감 −1.0/분, 행복 −0.8/분, 청결 −0.4/분(똥 1개당 −0.6 추가), 체력 −0.6/분(밤에는 −1.2)
- 밥: 포만 +30 / 간식: 포만 +8, 행복 +12, 청결 −4 / 씻기: 청결 100, 똥 치움
- 밥·간식 종류 랜덤 (v3): 줄 때마다 무작위로 나오며 같은 메뉴가 연속으로 나오지 않음. 효과(수치)는 종류와 상관없이 같음
  - 밥 4종: 주먹밥, 햄버거, 생선구이, 고기
  - 간식 4종: 케이크, 사탕, 아이스크림, 도넛
  - 먹이 받기 미니게임에서도 8종이 무작위로 떨어짐
- 욕조 목욕 (v3): 씻기를 누르면 펫이 욕조에 들어가 거품·비눗방울·수도꼭지 물방울과 함께 3초간 목욕하고 반짝임으로 끝남. 이미 깨끗해도 언제든 목욕 가능
- 불 끄기: 잠자기(체력 +2.5/분, 다른 수치는 천천히 감소), 체력이 0이 되면 스스로 잠듦
- 수치가 25 미만이면 경고음 + 메시지

### 이웃 친구 (v3.3)
- 놀이 메뉴의 다섯 번째 항목 "이웃 친구"
- 물·흙·하늘 세 계열의 모든 생물 중에서, 내 펫과 같은 성장 단계의 친구가 무작위로 놀러 옴(내 펫과 똑같은 모습만 제외)
- 공놀이: 친구가 공을 5번 던지고, 공이 내 쪽에 올 때 A 또는 B로 받아침. C를 누르면 그만 놀기(보상 없음)
- 보상: 행복 +10 + 받아친 공 1개당 +4 (최대 +30), 체력 −8, 포만 −5
- 친한 정도(하트 5칸): 같은 친구와 한 번 놀면 +1, 공을 3개 이상 받아치면 +2. 결과 화면에 하트로 표시

### 결혼 (v3.4)
- 조건: 내 펫이 어른이고, 이웃 친구와의 친한 정도가 5칸 가득 참 → 놀이가 끝난 뒤 "결혼할까요?" 선택지가 나옴
- "결혼하기"를 고르면 결혼식 장면(둘이 마주 보고 통통 뛰고 하트가 떠오름), 행복 100
- "아직은 친구로"를 고르면 다음에 그 친구와 놀았을 때 다시 물어봄
- 어른이고 결혼 전이면, 가장 친한 친구가 다시 찾아올 확률이 60%라 같은 친구와 친해지기 쉬움
- 결혼 뒤: 짝꿍은 집 화면에 나오지 않음(v3.5에서 변경, v3.4에서는 펫 옆에 함께 보였음). 결혼식 장면에만 나오고, 상태 화면에 "짝꿍 이름"으로 표시
- 결혼 뒤에도 다른 이웃 친구와 놀 수 있지만 청혼은 다시 나오지 않음. 가출하면 짝꿍 기록도 함께 사라짐

### 2세로 이어가기 (v3.5)
- 결혼하고 게임 시간으로 60분이 지나면 2세 알이 생김(다른 시간들과 같은 기준: 느긋 1시간, 보통 15분, 빠름 3분)
- 알의 계열은 내 펫의 계열과 짝꿍의 계열 중 하나가 반반 확률로 정해짐
- 알이 생기면 "2세로 이어가기 / 조금 더 함께 지내기"를 한 번 물어봄. 미루면 집 화면 왼쪽 아래에 작은 알이 놓이고, 설정의 "2세로 이어가기"에서 언제든 이어갈 수 있음
- 이어가기를 고르면 2세 이름을 짓고(C를 누르면 취소) 그 알부터 새로 키움. 문방구 컷신과 속도 선택은 건너뛰고, 속도·도감·기기 색은 그대로 유지
- 부모 펫과 짝꿍은 떠나고, 새 펫의 상태 화면에 "2세대"(이후 3세대, 4세대 …)가 표시됨. 부모 이름은 저장에 남지만 화면에는 아직 쓰이지 않음

### 가출
- 포만·행복·청결 중 0인 수치가 있으면 방치 시간이 쌓임(0인 수치 개수만큼 빠르게)
- 누적 120분(게임 시간)이 되면 편지를 남기고 가출 → 새 알 선택, 도감은 유지
- 수치가 모두 30을 넘으면 방치 시간이 천천히 줄어듦

### 밤낮
- 기기 시계 기준 21시~7시는 밤: 화면이 어두워지고 달·별 표시
- 밤에 2분간 조작이 없으면 자동으로 잠듦 (불을 켜면 깨어남)

### 저장
- 브라우저 localStorage 자동 저장(5초마다 + 화면을 닫을 때)
- 자리를 비운 시간은 속도 설정과 무관하게 ×0.5로 반영, 최대 8시간까지만 계산
- 밤에 돌아오면 자고 있던 것으로 처리

### 기타
- **도감 (v3.1에서 변경)**: 183칸, 16쪽. 1쪽은 아기 3종, 이후 계열마다 5쪽씩(한 쪽에 6종의 어린이·어른 짝). A 다음 칸, B 다음 쪽, C 닫기, 제목의 ◀ ▶를 눌러도 쪽이 넘어감. 도감을 열면 지금 키우는 펫이 있는 쪽이 먼저 보임
- 설정: 속도, 기기 색(딸기·민트·레몬·하늘·포도·먹물), 소리 켬/끔, 새 알로 다시 시작
- 효과음: Web Audio 사각파 비프음
- 글꼴: 둥근모꼴(웹폰트, 인터넷이 없으면 기본 고정폭 글꼴)

- "조금 더 함께 지내기"를 고르면 다시 묻지 않고, 설정에 "2세로 이어가기"가 생김
- 이름 짓기에서 C로 취소하면 원래 펫이 그대로 있음
- 이름을 넣고 이어가면 2세대 알로 시작하고, 부화하며, 새로고침 뒤에도 세대가 유지됨
- 실행 중 스크립트 오류 없음

아직 확인하지 못한 것:
- 알 위치를 한 칸 옮긴 뒤의 집 화면(옮기기 전 캡처에서 알이 왼쪽 끝에 붙어 보여서 옮김)
- 3세대 이상으로 이어가기, 자리를 비운 사이 알이 생겼을 때

### v3.1 ~ v3.4
자동 실행(헤드리스 브라우저에서 `tama-v3.4.html`을 직접 조작)으로 확인한 것:
- 오프닝: 가게 → 물건 3가지 고르기 → 간식 장면 → 학용품 장면 → 다마고치 → 알 고르기 → C로 물건 고르기 복귀 → 계산 → 이름 짓기
- 아기 → 어린이(30종 중 무작위) → 같은 종의 어른으로 진화, 도감 기록
- v3 형식의 옛 저장을 불러왔을 때 펫 모습과 도감이 새 번호로 옮겨짐
- 도감 쪽 넘기기(B, A 앞뒤, ◀ ▶ 누르기)
- 이웃 친구 공놀이 5번(4개 받아치고 1개 놓침) → 결과 화면의 하트 → 청혼 선택지 → 결혼식 → 집 화면에 짝꿍 표시(v3.5에서 없앰) → 상태 화면의 짝꿍 이름
- 결혼 뒤 이웃 친구로 짝꿍이 아닌 다른 친구가 오고, C로 그만 놀기
- 기존 미니게임 4종 진입, 실행 중 스크립트 오류 없음
- 화면 캡처로 본 것: 가게 물건 3가지, 공놀이, 결과, 결혼식, 집 화면, 상태, 도감 화면에서 글자 넘침이나 그림 겹침 없음

도트 그림 180장은 모아보기 그림으로 두 차례 훑어봄:
- 1차에서 50장이 알아보기 어렵다고 나와 그중 22장을 다시 그림
- 다시 그린 어른 16장 중 6장은 뚜렷, 9장은 "대략 그렇게 보임", 불사조 1장은 여전히 알아보기 어려움
- 다시 그리지 않은 것 중에도 어린이 그림(10×8칸 안팎) 20여 장은 무슨 동물인지 뚜렷하지 않음. 깨진 그림은 없음

아직 확인하지 못한 것:
- 가게 물건을 화면에서 직접 눌러 고르기(버튼·키 조작만 확인)
- "아직은 친구로"를 고른 뒤 다시 청혼이 나오는 흐름
- 어린이·아기 단계에서의 이웃 친구 놀이 화면
- 실제 휴대폰에서의 터치 조작과 소리
- 아래 v1~v3의 미확인 항목은 그대로 남아 있음
