## 2. 구현 내용 (v1~v3 누적)

### 화면·조작
- 달걀 모양 기기 + 48×32 도트 LCD, 위아래 아이콘 8개(밥·간식·놀이·씻기·불·상태·도감·설정)
- 버튼 A(이동) / B(선택) / C(취소), 아이콘·메뉴 직접 터치 가능
- 키보드: ←→ 이동, Enter 선택, Esc 취소, Z/X/C = A/B/C
- 펫을 누르면 쓰다듬기(행복 +2), 알을 누르면 부화가 조금 빨라짐

### 오프닝
타이틀 → 문방구 컷신 → 이름 짓기(최대 6글자) → 속도 선택 → 시작

**문방구 컷신 (v2 신규)** — 주인공은 모자 쓴 초등학생 "잼민이"

| 장면 | 내용 | 조작 |
|---|---|---|
| 1 | 잼민이가 용돈을 들고 문방구로 걸어감 | B 다음 / C 알 고르기로 건너뛰기 |
| 2 | 가게 안, 주인이 다마고치가 들어왔다고 알려줌 | B 다음 / C 건너뛰기 |
| 3 | 물·흙·하늘 알 3개 중 1개 고르기 | A(←→) 이동, B 선택, C 뒤로, 알을 직접 눌러도 됨 |
| 4 | 잼민이가 동전을 내고 계산 | B 구매 / C 다시 고르기 |
| 5 | 구매 완료, 잼민이가 알을 들고 기뻐함 | B → 이름 짓기 |

- 가출 후 새 알을 고를 때와 "새 알로 다시 시작"에서도 같은 컷신이 나옴
- 이름 짓기에서 C를 누르면 알 고르기 장면으로 돌아감

### 생물 (12종)
| 계열 | 아기 | 어린이 | 어른 A (잘 돌봄) | 어른 B (대충 돌봄) |
|---|---|---|---|---|
| 물 | 퐁퐁이 | 뽀글이 | 고래왕 | 먹물이 |
| 흙 | 콩콩이 | 깡총이 | 냥대장 | 느림보 |
| 하늘 | 뭉게 | 짹짹이 | 부엉박사 | 박쥐군 |

- 성장: 알(1분) → 아기(15분) → 어린이(45분) → 어른 (게임 시간 기준)
- 어른 형태: 아기~어린이 기간의 평균 상태(포만·행복·체력·청결)가 55 이상이면 A, 아니면 B

### 돌봄 수치 (0~100)
- 포만감 −1.0/분, 행복 −0.8/분, 청결 −0.4/분(똥 1개당 −0.6 추가), 체력 −0.6/분(밤에는 −1.2)
- 밥: 포만 +30 / 간식: 포만 +8, 행복 +12, 청결 −4 / 씻기: 청결 100, 똥 치움
- **밥·간식 종류 랜덤 (v3)**: 줄 때마다 무작위로 나오며 같은 메뉴가 연속으로 나오지 않음. 효과(수치)는 종류와 상관없이 같음
  - 밥 4종: 주먹밥, 햄버거, 생선구이, 고기
  - 간식 4종: 케이크, 사탕, 아이스크림, 도넛
  - 먹이 받기 미니게임에서도 8종이 무작위로 떨어짐
- **욕조 목욕 (v3)**: 씻기를 누르면 펫이 욕조에 들어가 거품·비눗방울·수도꼭지 물방울과 함께 3초간 목욕하고 반짝임으로 끝남. 이미 깨끗해도 언제든 목욕 가능(v2까지는 거절)
- 불 끄기: 잠자기(체력 +2.5/분, 다른 수치는 천천히 감소), 체력이 0이 되면 스스로 잠듦
- 수치가 25 미만이면 경고음 + 메시지

### 속도
| 이름 | 배속 | 어른까지 |
|---|---|---|
| 느긋 | ×1 | 약 1시간 |
| 보통 | ×4 | 약 15분 |
| 빠름 | ×20 | 약 3분 |

### 미니게임 (승리 시 행복 +28, 패배 시 +12, 체력 −8, 포만 −5)
| 게임 | 조작 | 승리 조건 |
|---|---|---|
| 좌우 맞히기 | A 왼쪽 / B 오른쪽 | 5번 중 3번 |
| 가위바위보 | A 가위 / B 바위 / C 보 | 3판 중 2승 (비기면 다시) |
| 먹이 받기 | A·B를 눌러 좌우 이동 | 10개 중 6개 |
| 점프 달리기 | A 또는 B로 점프 | 장애물 10개 중 5개 |

### 가출
- 포만·행복·청결 중 0인 수치가 있으면 방치 시간이 쌓임(0인 수치 개수만큼 빠르게)
- 누적 120분(게임 시간)이 되면 편지를 남기고 가출 → 새 알 선택, 도감은 유지
- 수치가 모두 30을 넘으면 방치 시간이 천천히 줄어듦

### 밤낮
- 기기 시계 기준 21시~7시는 밤: 화면이 어두워지고 달·별 표시
- 밤에 2분간 조작이 없으면 자동으로 잠듦 (불을 켜면 깨어남)

### 저장
- 브라우저 localStorage 자동 저장(5초마다 + 화면을 닫을 때)
- 자리를 비운 시간은 속도 설정과 무관하게 ×0.5로 반영, 최대 8시간까지만 계산
- 밤에 돌아오면 자고 있던 것으로 처리

### 기타
- 도감: 만난 형태 12칸 수집
- 설정: 속도, 기기 색(딸기·민트·레몬·하늘·포도·먹물), 소리 켬/끔, 새 알로 다시 시작
- 효과음: Web Audio 사각파 비프음
- 글꼴: 둥근모꼴(웹폰트, 인터넷이 없으면 기본 고정폭 글꼴)

## 3. 검증 내역

### v3
브라우저에서 직접 확인한 것:
- 밥(고기), 간식(아이스크림)이 무작위 메뉴로 나오고 이름이 메시지에 표시됨
- 씻기 시 욕조 장면이 나오고 펫이 욕조 안에 들어가 보임
- 컷신에서 C로 알 고르기로 건너뛰기

아직 직접 확인하지 못한 것:
- 나머지 음식 6종의 도트 그림, 먹이 받기에서의 새 음식 표시
- 욕조 장면의 끝부분(반짝임)과 어른 형태가 욕조에 들어간 모습

### v2
브라우저에서 직접 확인한 것:
- 타이틀 → 문방구 컷신 5장면 → 이름 → 속도 → 물의 알로 게임 시작까지 전체 흐름
- 알 고르기에서 키보드 이동과 알 직접 누르기(한 번 누르면 선택, 다시 누르면 결정)

아직 직접 확인하지 못한 것:
- 컷신의 C(건너뛰기·뒤로) 동작, 가출 후 컷신 재진입
- 아래 v1의 미확인 항목은 그대로 남아 있음

### v1

브라우저에서 직접 확인한 것:
- 오프닝 전체 흐름(알 선택 → 한글 이름 입력 → 속도 선택)
- 부화, 아기 → 어린이 진화, 밥 주기, 씻기, 불 끄기(어두운 화면), 상태, 도감
- 좌우 맞히기, 가위바위보, 점프 달리기
- 새로고침 후 저장 복원

아직 직접 확인하지 못한 것:
- 먹이 받기 게임, 가출 흐름, 어른 진화 분기
- 물·하늘 계열과 어른 형태 도트 그림의 실제 화면 모습
- 실제 휴대폰에서의 터치 조작과 소리
