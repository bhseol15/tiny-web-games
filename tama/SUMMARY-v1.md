## 1. 인터뷰 결과 (확정 사항)

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 + 모바일 (반응형 단일 HTML) |
| 컨셉 | 바다 · 육지 · 하늘 생물 등 여러 계열 |
| 생물 결정 방식 | 오프닝에서 다마고치 스타일(알) 선택 |
| 그래픽 | 레트로 LCD 픽셀 (기기 프레임 + 도트 화면) |
| 핵심 기능 | 기본 돌봄, 성장·진화, 미니게임, 효과음, 자동 저장 |
| 게임 속도 | 게임 안에서 선택 가능 |
| 미니게임 | 좌우 방향 맞히기, 가위바위보, 먹이 받기, 점프 달리기 |
| 방치 시 | 가출 (사망 없음) |
| 부가 요소 | 도감, 펫 이름 짓기, 밤낮 변화, 기기 색상 선택 |

## 2. v1 구현 내용

### 화면·조작
- 달걀 모양 기기 + 48×32 도트 LCD, 위아래 아이콘 8개(밥·간식·놀이·씻기·불·상태·도감·설정)
- 버튼 A(이동) / B(선택) / C(취소), 아이콘·메뉴 직접 터치 가능
- 키보드: ←→ 이동, Enter 선택, Esc 취소, Z/X/C = A/B/C
- 펫을 누르면 쓰다듬기(행복 +2), 알을 누르면 부화가 조금 빨라짐

### 오프닝
타이틀 → 알 선택(바다/육지/하늘) → 이름 짓기(최대 6글자) → 속도 선택 → 시작

### 생물 (12종)
| 계열 | 아기 | 어린이 | 어른 A (잘 돌봄) | 어른 B (대충 돌봄) |
|---|---|---|---|---|
| 바다 | 퐁퐁이 | 뽀글이 | 고래왕 | 먹물이 |
| 육지 | 콩콩이 | 깡총이 | 냥대장 | 느림보 |
| 하늘 | 뭉게 | 짹짹이 | 부엉박사 | 박쥐군 |

- 성장: 알(1분) → 아기(15분) → 어린이(45분) → 어른 (게임 시간 기준)
- 어른 형태: 아기~어린이 기간의 평균 상태(포만·행복·체력·청결)가 55 이상이면 A, 아니면 B

### 돌봄 수치 (0~100)
- 포만감 −1.0/분, 행복 −0.8/분, 청결 −0.4/분(똥 1개당 −0.6 추가), 체력 −0.6/분(밤에는 −1.2)
- 밥: 포만 +30 / 간식: 포만 +8, 행복 +12, 청결 −4 / 씻기: 청결 100, 똥 치움
- 불 끄기: 잠자기(체력 +2.5/분, 다른 수치는 천천히 감소), 체력이 0이 되면 스스로 잠듦
- 수치가 25 미만이면 경고음 + 메시지

### 속도
| 이름 | 배속 | 어른까지 |
|---|---|---|
| 느긋 | ×1 | 약 1시간 |
| 보통 | ×4 | 약 15분 |
| 빠름 | ×20 | 약 3분 |

### 미니게임 (승리 시 행복 +28, 패배 시 +12, 체력 −8, 포만 −5)
| 게임 | 조작 | 승리 조건 |
|---|---|---|
| 좌우 맞히기 | A 왼쪽 / B 오른쪽 | 5번 중 3번 |
| 가위바위보 | A 가위 / B 바위 / C 보 | 3판 중 2승 (비기면 다시) |
| 먹이 받기 | A·B를 눌러 좌우 이동 | 10개 중 6개 |
| 점프 달리기 | A 또는 B로 점프 | 장애물 10개 중 5개 |

### 가출
- 포만·행복·청결 중 0인 수치가 있으면 방치 시간이 쌓임(0인 수치 개수만큼 빠르게)
- 누적 120분(게임 시간)이 되면 편지를 남기고 가출 → 새 알 선택, 도감은 유지
- 수치가 모두 30을 넘으면 방치 시간이 천천히 줄어듦

### 밤낮
- 기기 시계 기준 21시~7시는 밤: 화면이 어두워지고 달·별 표시
- 밤에 2분간 조작이 없으면 자동으로 잠듦 (불을 켜면 깨어남)

### 저장
- 브라우저 localStorage 자동 저장(5초마다 + 화면을 닫을 때)
- 자리를 비운 시간은 속도 설정과 무관하게 ×0.5로 반영, 최대 8시간까지만 계산
- 밤에 돌아오면 자고 있던 것으로 처리

### 기타
- 도감: 만난 형태 12칸 수집
- 설정: 속도, 기기 색(딸기·민트·레몬·하늘·포도·먹물), 소리 켬/끔, 새 알로 다시 시작
- 효과음: Web Audio 사각파 비프음
- 글꼴: 둥근모꼴(웹폰트, 인터넷이 없으면 기본 고정폭 글꼴)

## 3. 검증 내역 (v1)

브라우저에서 직접 확인한 것:
- 오프닝 전체 흐름(알 선택 → 한글 이름 입력 → 속도 선택)
- 부화, 아기 → 어린이 진화, 밥 주기, 씻기, 불 끄기(어두운 화면), 상태, 도감
- 좌우 맞히기, 가위바위보, 점프 달리기
- 새로고침 후 저장 복원

아직 직접 확인하지 못한 것:
- 먹이 받기 게임, 가출 흐름, 어른 진화 분기
- 바다·하늘 계열과 어른 형태 도트 그림의 실제 화면 모습
- 실제 휴대폰에서의 터치 조작과 소리
