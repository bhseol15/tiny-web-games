## 1. 프로젝트 개요

아파트 평면도를 바탕으로 Three.js 기반 3D 집 공간을 만들고, 집을 탐색하고 가구를 배치하며 생활하는 웹 게임을 개발했다. 이후 집 옆 마트, 쇼핑·결제, 음식 섭취·보관·조리, 가족 NPC, 선택형 공포 모드, 배달앱, 반려동물, 체력 시스템으로 범위가 확대되었다.

- 초기 구성: HTML/CSS/JavaScript와 Three.js를 사용하는 단일 파일 웹 애플리케이션.
- 원본에서 평면도를 “109A㎡, 4베이 판상형”으로 설명했지만, 원본 평면도 이미지나 실측 자료는 이 정리에서 확인하지 않았다.
- PC 키보드·마우스와 모바일 멀티터치 조작을 함께 지원하는 방향.
- 일반 생활 모드와 공포 모드를 선택하는 방향.

### 모바일 조작

- 초기 D-Pad를 터치 드래그형 360도 가상 조이스틱으로 교체.
- 기울기 방향·거리에 비례해 이동 방향과 속도 조절.
- 조이스틱 이동과 다른 손가락 시점 회전을 동시에 처리.
- 짧은 탭은 설치·문 열기·상호작용, 길게 누르기는 가구 철거로 설명.
- 우측에 상호작용, 철거, 점프·상승, 비행, 회전 버튼 배치.
- 작은 화면에서 미니맵 접기·펼치기 및 UI 크기 조절.
- 조이스틱 외곽 원과 노란 조작부의 동심원 정렬을 반복 수정.
- 드래그 반경 계산 및 손을 뗐을 때 중앙 복귀 처리.
- 후기 전체 복구 이후 조이스틱이 사라졌다는 사용자 보고가 있어 복구 확인 필요.

### 하단 메뉴의 최종 방향

1. 초기에는 가구 1~9번을 나열한 핫바/퀵슬롯 사용.
2. 0번 빈손 추가. 같은 선택을 다시 누르면 빈손으로 전환.
3. 하단 메뉴를 화면 정중앙 아래에 고정.
4. 가구 목록을 별도 가구 가방 버튼과 팝업으로 분리.
5. 빈손 옆에는 구매한 음식 슬롯을 표시.
6. 음식 보관 편의를 위한 냉장고 넣기 버튼 추가 설명.

## 5. 가구 배치·생활 상호작용·충돌

### 가구 편집

- 소파, 거실장·TV, 식탁, 침대, 옷장, 책상, 화분, 러그, 스탠드 조명 등.
- 바닥 위치 지정, 배치 고스트 프리뷰, 대상 외곽선 표시.
- 조감도에서 드래그 이동, 가구 회전·색상 변경·삭제.
- 플레이어 몸과 겹치는 위치에 설치하지 않도록 제한.

### 빈손 생활 상호작용

- 소파·의자 앉기, 침대 눕기. 이동하거나 점프하면 일어나기.
- 식탁·아일랜드의 식사 차리기 및 먹기.
- 주방 싱크대, 건식 세면실·부부욕실 세면대, 욕조의 물 켜기·끄기.
- TV·스탠드 조명 전원 전환.
- TV를 켤 때 뉴스, 축구, K-POP, 요리, 자연 다큐 등 랜덤 프로그램 화면 표시.
- 양문형 냉장고 문 열기·닫기.

### 충돌 규칙

- 벽, 창문, 닫힌 문, 주방·욕실 설비, 붙박이장 및 입체 가구 통과 방지.
- 벽에 닿으면 벽을 따라 미끄러지며 이동하는 방식 설명.
- 문을 열면 통과하고 닫으면 차단.
- 러그는 보행 가능. 초기 설명에는 조명도 충돌 예외로 언급되어 최종 정책 확인 필요.
- 착석·취침 해제 시 안전 위치로 복귀해 끼임 방지.

## 6. 집 옆 24시 마트와 쇼핑

### 공간·상품

- 현관문을 나가면 옆 마트로 이동.
- 상품이 가려지던 박스형 진열대를 3단 오픈 선반으로 변경.
- 일반 진열대를 벽면에 붙여 중앙 통로 확보.
- 음료팩·캔, 과자 봉지·원통형 감자칩, 과일팩, 컵라면, 삼각김밥 등을 개별 3D 모형으로 표시.
- 알바생 옆에 냉장 쇼케이스를 추가하고 우유, 삼각김밥, 도시락 등 진열.

### 바구니·결제·구매품

1. 입구 거치대에서 쇼핑 바구니를 들거나 반납.
2. 개별 상품을 클릭하면 선반에서 사라지고 손바구니에 같은 음식 모형 추가.
3. 바구니의 각도·높이를 조절해 내용물이 보이도록 개선.
4. 계산대나 알바생과 상호작용하면 영수증·수량·총액 표시.
5. 현금 또는 카드 선택 후 결제.
6. 구매품은 빈손 옆 인벤토리에 수량과 함께 추가.
7. 결제 후 바구니 비우기 및 진열대 재입고 설명.
8. 구매품을 손에 들고 먹거나 마시면 수량 차감.

- 초기 현금 보유액 설명: 50,000원.
- 카드 단말기, POS, 현금 금고를 3D로 배치.
- 알바생은 계산대 건너편에서 손님을 마주보도록 수정.
- 유니폼·명찰, 인사, 시선 추적, 손 흔들기, 대화·결제 기능 설명.
- 후기에는 알바생도 계산대 뒤를 걷는 기능 추가.
- 결제는 게임 내 기능 설명이며 실제 금융 결제 연동으로 확인된 것은 아니다.

## 7. 음식 조리·냉장고 보관

- 구매한 음식을 손에 들고 사용하면 먹거나 마시기.
- 컵라면은 주방 싱크대 온수 등과 상호작용해 조리된 음식으로 전환.
- 김·젓가락 효과 설명. “3분 대기 완료” 메시지는 있지만 실제 3분 타이머인지는 확인되지 않음.
- 구매·배달 음식을 냉장고에 넣고 다시 꺼내기.
- 냉장고 관리 모달에서 가방 ↔ 냉장고 이동.
- 냉장고 내부를 속이 빈 5면 캐비닛으로 만들고 LED·유리 선반 추가.
- 보관 음식은 선반 위 3D 모형으로 보이게 하고 직접 클릭해 꺼내기.
- 음식이 든 손으로 닫힌 냉장고를 클릭하면 문이 열리며 보관되도록 개선 설명.
- 하단 냉장고 넣기 버튼 제공 설명.

## 8. 거주 형태·가족 NPC

| 모드 | 요청 | 대화 속 설명 |
|---|---|---|
| 혼자 살기 | 성인, 높은 눈높이 | 1.72m |
| 가족과 함께 살기 | 어린이, 낮은 눈높이 | 1.10m 및 1.08m가 혼재 |

- 시작 모달에서 선택하고 상단 버튼으로 변경.
- 가족 모드에서 엄마, 아빠, 막내 동생 NPC 배치.
- 가족들이 거실·주방·복도·방을 걸어 다니며 팔·다리 교차 스윙과 보행 바운스 적용 설명.
- 귀신 변신 상태도 이동하며, 알바생 보행 추가 설명.
- 어린이 눈높이의 최종 수치는 소스 확인 필요.

## 9. 선택형 공포 모드

### 기본 규칙

- 시작 설정 또는 상단 버튼에서 ON/OFF.
- 혼자 살기 + 밤: 유리창 밖에 귀신이 가끔 출몰.
- 가족과 함께 살기 + 밤: 가족이 무작위로 귀신으로 변했다가 복귀.
- 밤에 마트 알바생도 귀신으로 변신.
- 침실 1은 안전 구역으로 유지하고 나머지는 흉가 분위기로 변경.
- 어두운 벽지, 얼룩, 붉게 깜빡이는 조명, 귀신 접근 효과 설명.
- 외형·관절 움직임·돌진·음향·붉은 비네팅 등 공포 연출 강화 요청.

### 안전 구역 규칙의 최종 방향

1. 귀신은 침실 1에 들어올 수 없다.
2. 결계에 부딪히면 큰 충돌음, 섬광, 파편·수축 효과와 함께 소멸한다.
3. 소멸 이후 잠시 뒤 현관에서 진짜 가족 또는 가짜 귀신 가족이 다시 들어온다.
4. 진짜 가족은 안전 구역에 들어와 안심시킬 수 있다.
5. 플레이어가 안전 구역에 있으면 귀신은 문 앞에 몰리지 않고 다른 공간을 분산 배회한다.
6. 우연히 결계에 닿거나 추격 중 충돌한 귀신의 소멸 규칙은 유지한다.

초기의 “결계 충돌 즉시 진짜 가족으로 정화” 설명은 이후 “소멸 후 현관 재진입” 요청으로 변경되었다. 재진입 지연 약 2.6초 및 진짜/가짜 50% 확률은 이전 답변의 설명값으로, 사용자가 직접 지정한 수치는 아니다.

### 원본 평면도 vs 3D 조감도 점검 (v2 기준, 미수정 참고 사항)
- 방 배치·방향은 일치함(회전·반전 없음).
- 비율: 원본 이미지 기준으로 다시 환산하니 축척이 3D와 같았음(가로 19.1m×세로 13.6m). 남측 외곽선 돌출 문제는 #11에서 해결.
- 북측: 원본은 현관 오른쪽 침실이 북쪽으로 돌출되어 있음. 3D는 이 침실을 거실과 통합(이전 요청)했으므로 유지함.
- 가로 방향 칸막이: 원본은 침실2 동측 x≈-1.8, 안방 서측 x≈4.5. 3D는 -2.2와 3.8로 거실이 약 0.3m 좁음. 많은 가구를 옮겨야 해서 미수정.
- 주방: 3D 주방이 원본보다 좁고, ㄱ자 아일랜드 형태가 뚜렷하지 않음.
- 드레스룸 동쪽 창: 원본에는 있으나 3D는 그 자리에 붙박이장(x=9.05)이 있어 추가하지 않음.
- 안방 침대: 원본에서의 위치는 확인 불가. 사용자 요청대로 동쪽 벽에 붙였고, 창은 헤드보드 위의 높은 창으로 처리함.

### 구현 메모
- 참고: 문에는 원래 충돌 판정이 없어, 닫힌 문도 플레이어·NPC가 통과할 수 있음(v1부터 동일).
- 기존 코드 변경: `crouchBlend` 변수 추가, 카메라 높이·이동 속도에 웅크리기 반영, 상단 버튼·미니맵 박스·모바일 숙이기 버튼 HTML 추가.
- 나머지 기능은 `</body>` 직전 별도 `<script>` IIFE(v2 추가 기능)로 분리 → 기존 로직 영향 최소화.
- 가구 복원은 기존 `placeSelectedFurnitureAt()`을 재사용(충돌 박스·상호작용 자동 등록), 복원 중 토스트 억제.
- 저장 대상 아님: 반려동물·가족 구성·공포/주야 모드·플레이어 위치·진행 중 배달.

### v2 검증
- 스크립트 파싱 OK, 페이지 로드 콘솔 오류 없음.
- 신규 버튼 표시, 휠로 가구(몬스테라) 선택, 미니맵 접기 동작 확인.
- 저장 데이터 주입(현금 12,345원·HP 77·곰인형 1개) → 로드 시 UI 반영 및 「저장된 진행 상황을 불러왔습니다」 토스트 → 재저장 시 가구 데이터 유지 확인.
- 미검증: 실제 모바일 기기 터치, 스크린샷 파일 다운로드, 웅크리기 체감 높이.
